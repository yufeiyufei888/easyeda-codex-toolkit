# EasyEDA 工程学习与审查：只读记忆

“学习工程”“学习原理图”“学习 PCB 绘制”“审查/检查”默认是严格只读任务：只连接、读取、观察、检查和总结；不编辑、不整理、不保存、不自动修复。

## 原理图

只读取理解功能所必需的信息，分析功能分区、信号/电源流、元件与网络、符号和标签、连线、可读性、标注和检查方法。将结论分为：已确认的重点规则、与现有技能不同或新增的规则、工程特有做法、待确认问题、以及有充分证据支持的潜在错误。

## PCB

先从关联原理图恢复设计意图，再检查板框和结构约束、模块分区、器件摆放、关键回路、走线、过孔、铺铜、回流路径、层叠、间距、丝印、接口和可制造性。

自动检查只提供候选证据；必须结合网表、几何关系和视觉结果核实。无法从工程、可靠资料或数据手册确认的内容不猜测，应标记为待用户确认。
