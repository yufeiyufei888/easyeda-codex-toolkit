# 电源方案选型决策树

## 一级决策：确定拓扑

```
                        ┌── 是 ── 电流 > 500mA 或 压差 > 2V？
                        │            ├── 是 → Buck DCDC（同步Buck优先）
                        │            └── 否 → LDO
输入电压 > 输出电压？ ──┤
                        ├── 否 ── 输入电压 < 输出电压？
                        │            ├── 是 → Boost DCDC
                        │            │         └── 注意：需短路保护需在输入端串MOSFET
                        │            └── 否 → 输入可能高于也可能低于输出？
                        │                      └── 四开关Buck-Boost
                        └── 需要隔离？ → 反激 / 正激 / 隔离Buck（变压器/容隔/光隔）
```

## LDO vs DC/DC 详细对比

| 维度 | LDO | Buck DCDC |
|------|-----|-----------|
| 效率 | 低（≈Vout/Vin），压差越大效率越低 | 高（85%~95%） |
| 发热 | 严重（Pd=(Vin-Vout)×Iout） | 低 |
| 输出纹波 | 极低 | 中等（电感+电容滤波后仍有一定纹波） |
| 占板面积 | 极小（芯片+2个电容） | 较大（芯片+电感+输入输出电容+反馈电阻） |
| 成本 | 低 | 中 |
| EMI | 几乎无 | 有开关噪声 |
| 适用电流 | < 500mA（典型） | 数百mA~数十A |
| 瞬态响应 | 好 | 一般 |

**LDO选型注意事项**：
- 选用低压差LDO（Dropout Voltage）：3.7V锂电池最低电压约3.3V，普通LDO（压差1.1V）无法可靠输出3.3V。
- LDO放在待机通路的MOS管之后，避免静态电流额外消耗。
- 电池供电+LDO做缓冲器：克服瞬时波动（如电流源短路测试时的电压波动），尤其低频场景效果好。
- LDO作电流源：选用可调且无接地引脚的型号，利用反馈形成恒流源（精度不如运放方案但简单够用）。

**Buck DCDC选型注意事项**：
- 优先选同步Buck（下管用MOSFET而非二极管），效率更高、体积更小。
- 输入电容必须靠近芯片Vin和GND引脚，否则线路寄生电感引起输入电压尖峰，可能击穿MOSFET。
- 输出电容推荐X7R/X5R材质陶瓷电容（温度/电压特性好），低纹波场景搭配低ESR电容。
- 电感量计算公式：L = (Vin-Vout)×D / (ΔIL×fsw)，ΔIL通常取Iout的20%~40%。
- 电感额定电流和饱和电流必须大于峰值电流：Ipk = Iout + 0.5×ΔIL。

## 规格书快速阅读清单

拿到一颗DCDC芯片，优先关注以下10项（不必逐行阅读整个规格书）：

| 序号 | 参数 | 英文名 | 为什么重要 |
|------|------|--------|-----------|
| 1 | 上下管导通阻抗 | Rds(on) | 直接决定导通损耗和发热，同等级越小越好 |
| 2 | 开关频率 | fsw | 影响开关损耗、电感体积、EMI |
| 3 | 电流限值 | Current Limit | 做OCP/SCP保护，注意不等于输出电流（Ipk=Iout+0.5ΔIL） |
| 4 | 关断电流 | Shutdown Current | EN关闭时的输入电流 |
| 5 | 静态电流 | Quiescent Current | 芯片使能但无输出时的逻辑电路电流，**不是待机电流** |
| 6 | 最大占空比 | Max Duty | 受自举电路充电时间限制，不可能100%，限制最大输出电压 |
| 7 | EN阈值与迟滞 | EN Threshold & Hysteresis | 避免在阈值附近反复开关 |
| 8 | 软启动时间 | Soft-Start | 防止输出电压过冲 |
| 9 | 结温与热阻 | TJ, θJA, θJC | TJ = TA + PD×θJA（环境）或 TJ = TC + PD×θJC（壳温） |
| 10 | Power Good引脚 | PG | 输出电压正常时拉高，过压/欠压拉低，可用于上电时序控制 |

## 控制模式简介

- **峰值电流控制（PCM）**：电压外环+电流内环，定频。优点是逐周期限流保护、响应快；缺点是占空比>50%需斜坡补偿防次谐波振荡。
- **斜坡补偿**：占空比越大，有效电流限值越低（补偿斜坡叠加效应）。

## 功率损耗组成

| 损耗类型 | 公式/关系 | 轻载占比 | 重载占比 |
|---------|----------|---------|---------|
| 导通损耗 | I²×Rds(on)（上下管）+ I²×DCR（电感） | 低 | 高（与I²成正比） |
| 开关损耗 | 与fsw正相关、与负载几乎无关 | 高 | 低 |
| 效率曲线 | 抛物线形 | 轻载低效 | 中载最优→重载下降 |

## 常见电源方案速查

| 场景 | 典型输入 | 所需输出 | 推荐方案 | 参考芯片 |
|------|---------|---------|---------|---------|
| 2S锂电池供电MCU | 6V~8.4V | 3.3V/200mA | 优先比较Buck与LDO；LDO必须核算最坏耗散、结温和掉电裕量 | 按准确输入范围、效率、静态电流和热设计选型 |
| 2S锂电池供电小车 | 6V~8.4V | 电机支路+3.3V逻辑 | 电机支路按驱动/电机范围设计；逻辑电源用Buck或经热核算的LDO | 分支保护、地回流和堵转瞬态需一起验证 |
| 1S锂电池升压5V | 3.0V~4.2V | 5V/1A | Boost DCDC | 按最低输入时电池电流、效率、电感饱和与环路稳定性选型 |
| 5V USB转3.3V | 5V | 3.3V/500mA | 比较LDO与Buck；LDO最坏耗散约0.85W，须验证封装散热 | 按负载瞬态、噪声和热设计选型 |
| 12V转5V大电流 | 12V | 5V/3A | Buck DCDC | 同步Buck芯片 |
| 电池供电+隔离 | 3.7V | 3.3V隔离输出 | 合规隔离DC/DC拓扑/模块 | 隔离耐压、爬电间距、负载和安规按项目标准确定 |

## 模拟/数字混合电路供电原则

- 默认使用连续、低阻抗的GND参考面，通过功能分区、器件摆放和受控回流避免高 `di/dt` 数字/开关电流穿过敏感模拟区。
- AVDD、VREF等敏感电源是否通过磁珠、RC或独立稳压器滤波，按准确器件数据手册、噪声频谱、直流偏置、压降和去耦回路设计。
- 只有隔离架构、准确器件要求或回流分析明确需要时才拆分AGND/DGND；此时定义唯一汇合点，并确保跨域信号不跨越无回流路径的平面缝隙。
- 磁珠并非“加了也无害”：它可能引入压降、谐振、瞬态阻抗或意外回流，是否使用与供电来源无直接二选一关系。

## 防反接与保护

- 电池输入端串防反接二极管（肖特基，低压降）。
- 输入加TVS管防浪涌。
- 电机驱动芯片供电分支不经LDO，直接从电池取电（经开关和防反接二极管后）。
