## 1. 智能小车

### 项目概述
四轮驱动智能小车，支持遥控、循迹、避障等功能，适合电赛/毕设/学习。

### 系统架构
```
锂电池(7.4V 2S) ─┬─→ [直供] 电机驱动(RZ7899×4) ─→ 4×N20直流电机
                 ├─→ [3.3V LDO] AMS1117-3.3 ─→ MCU(GD32F450) + 蓝牙 + OLED
                 └─→ [ADC分压] 电量检测
```

### 核心模块清单
| 模块 | 方案 | 关键参数 |
|------|------|---------|
| 主控 | GD32F450（梁山派开发板） | 200MHz, M4+FPU, 多路定时器PWM |
| 电机 | N20微型金属齿轮减速电机 | 6V, 300~500转/分, 堵转2A(定制款) |
| 电机驱动 | RZ7899 × 4 | 外围简单, 电池直供, 高低电平组合控制正反转 |
| 循迹 | 5路红外对管 + LM393比较器 | 数字型, 滑动变阻器调灵敏度 |
| 避障 | HC-SR04超声波 | 3V~5.5V, 最大6m, 精度3mm |
| 通信 | HC-05蓝牙(UART) / LS12 2.4G | UART交叉连接, 9600/115200波特率 |
| 显示 | OLED 0.96寸 | I2C |
| 电源 | 2S锂电池 7.4V | 7.4V直供电机, 经AMS1117-3.3供MCU |
| 电量检测 | 电阻分压 + ADC | 两个10K串联+一个10K到地 |

### 关键设计决策
- 电机选型公式：目标速度 ≈ 1m/s, 轮径4.2cm → 周长0.132m → 约455转/分。
- N20电机有通用款（15000转原始/30:1减速比，堵转350mA）和定制款（25000转/50:1减速比，堵转2A），力矩差距5倍以上。
- 电机两端并联104电容，焊在电机端子上而非PCB上（厂家建议）。
- 减少物料种类：用两颗已有料号的10K串联代替一颗20K，避免新增BOM料号。

### 引脚分配要点
- 左侧两轮用定时器2的通道0~3（AF2），右侧两轮用定时器1的通道0~3（AF1）。
- 5路循迹用GPIO输入上拉。
- 超声波Trig→PB12(输出)、ECHO→PB10(输入下拉)。
- ADC电量检测用PC5（ADC01_CH15）。

### 技术难点
- 四轮独立PWM调速算法（差速转向）。
- 超声波测距公式：距离 = 高电平时间 / 2 × 340 / 1000。
- 蓝牙中断接收+指令解析。

## 2. 简易示波器

### 项目概述
基于STM32H750的简易示波器，模拟前端支持正负15V输入、双通道同步采集。

### 系统架构
```
模拟输入 → 输入衰减(1MΩ) → 档位切换(信号继电器) → 同相比例放大+偏置 → ADC
                                                              ↓
触发电平(DAC/PWM) → 迟滞比较器 → TRIGGER_OUT → 定时器捕获 → 触发ADC采集
                                                              ↓
DAC输出 → LPF → 反相比例放大+偏移 → 50Ω输出 → 信号源输出
```

### 核心设计
- **数学建模法**：y = Ax + B。输入±15V → 输出0~3.3V。解得A≈0.11（1/9衰减）、B=1.65V偏置。
- **输入阻抗**：1MΩ（与商业示波器一致），用大阻值分压电阻。
- **迟滞比较器**：必须用滞回比较器（AP331），1MΩ/10KΩ约100:1迟滞比，防止毛刺多次误触发。
- **双重ADC同步模式**：ADC1(主)+ADC2(从)，同步采样→32位ADC_CDR寄存器→DMA搬运。
- **触发电平生成**：PWM + 两级RC低通滤波 → 运放跟随器 → 比较器（低成本方案，无需DAC）。
- **信号源输出**：DAC→低通滤波→反相比例放大6倍→-10V偏移→50Ω输出阻抗。
- **采样率计算**：ADC时钟20MHz，16位分辨率（1.5+8.5=10周期），采样率=2MSPS。

### 技术难点
- 模拟前端偏置电路：运放负向端输入-1.65V实现直流偏置。
- 输出保护：运放输出串小电阻+双二极管钳位。
- 衰减补偿电容：分压电阻并联2.2pF，高频补偿（低频可不焊）。

## 3. 多功能测试笔

### 项目概述
基于CW32F030的便携式多功能测试笔，支持逻辑电平检测、通断检测、LED点亮、信号源输出、模拟电平输出。

### 系统架构
```
探针 → 模拟开关(功能切换) → ADC → CW32F030 → BLE → 手机APP
                              ↓                  ↓
                         电流源DAC输出          OLED屏
```

### 核心需求合并
五个功能需求归为三个核心：电压输入检测(ADC)、信号输出(DAC+放大)、电流源（LDO恒流方案）。

### 关键设计决策
- **电气隔离**：BLE无线通信替代USB有线连接，防止被测高压串入电脑。
- **体积约束**：固态继电器（光耦继电器）替代传统继电器。
- **功耗优化**：LDO放在待机通路MOS管之后，延长待机时间。
- **校准流程**：探针与地短接→采集100次取平均→存入Flash作为校准值。
- **输入保护**：前卫电压+二极管构成钳位保护。

### 电源设计
- 升压：MT3608输出所需电压 → LC滤波，电感选小型号但需保证额定电流和饱和电流满足。
- LDO多用途：①缓冲克服瞬时波动 ②升降压匹配测量范围 ③作为恒流源（选可调无接地引脚型号）。
- 模拟地与数字地用磁珠分隔。

### 技术难点
- 模拟开关功能切换电路。
- ADC多通道DMA采样+滤波算法。
- BLE低功耗通信协议设计。

## 4. WIFI控制器

### 项目概述
基于ESP32-C3的WiFi远程控制器，通过云平台控制GPIO输出。

### 系统架构
```
Type-C(5V) → LDO(3.3V) → ESP32-C3模组 → GPIO → MOSFET → 输出端子
                           ↓
                      按键输入(上拉/下拉)
```

### 核心设计
- ESP32-C3模组直接使用，外围极简。
- GPIO直驱MOS管（PMOS用于电源开关，VGS=0关断/VGS>0导通）。
- MQTT协议连接巴法云平台。
- 开发环境：ESP-IDF + VS Code。

### 技术难点
- MQTT断线重连机制。
- 云平台指令下发与状态上报。

## 5. 温湿度仪

### 项目概述
基于STM32G0+盛思睿温湿度传感器的便携仪表，两节5号电池供电。

### 系统架构
```
两节5号电池(3V) → [无需降压] → STM32G071 + 温湿度传感器
                                  ↓
                            电池电压ADC采样 → 电量显示
```

### 关键教训
- **晶振选型铁律**：必须查数据手册！STM32G0 K6T6只支持低速无源+高速有源晶振，用8MHz无源晶振导致代码跑不通。
- I2C上拉电阻：典型4.7KΩ，若传感器模块内部已集成则外部可省略。
- 电阻分压精度：电池采样选用0.1%精度电阻。
- 电池供电（无DCDC）可省磁珠。

## 6. DAPLink下载器

### 项目概述
基于AT32F425的ARM调试器，支持SWD/JTAG/UART。

### 系统架构
```
Type-C(5V) → LDO(5V→3.3V) → AT32F425 → 排针输出(SWD/JTAG/UART)
```

### 关键设计
- 有源晶振 vs 无源晶振：下载器对时钟精度要求高，推荐有源晶振（仅接OSC_IN）。
- NRST引脚：内部已有10K上拉，外部仅需100nF电容。
- PCB布局流向：Type-C左进→LDO→MCU→排针右出。

## 7. 四层板USB HUB

### 项目概述
基于CH634X的USB 3.0 HUB + 100W PD快充，四层板设计。

### 核心设计
- 隔离方案：ISOUSB211（1500V隔离）+ 反激变压器辅助供电。
- 电流监控：INA226 × 4颗，I2C总线传主控。
- USB口独立控制：SY6288CAC开关芯片控制各路VBUS。

## 8. 无刷电机驱动

### 项目概要
基于CW32的FOC无刷电机驱动，三块分离板（核心板+控制底板+功率板）便于学习。

### 核心架构
```
MCU → 6路PWM → 栅极驱动芯片 → 6颗MOSFET(三相桥) → UVW三相电机
```

### 关键设计
- 三相桥式MOS管驱动：绝对禁止上下桥同时导通（瞬间短路烧管）。
- 集成方案：DRV8870（正反转，最大3.6A，6.5V~45V）。
- PID闭环控制：先调PI，D项可暂缓；抗积分饱和（Anti-windup）；建议计算周期~20ms。
- 学习路径：点灯→电机跑起来→再学理论（不要一开始看太多理论）。

## 9. 心形流水灯

### 项目概要
基于STC单片机的32颗LED流水灯，74HC595移位寄存器驱动，心形PCB外形。

### 关键设计
- PCB外形：两点圆弧+折线工具绘制心形。
- 网格设置：外形设计用2mm网格，布局时改为0.254mm。
- 74HC595级联驱动32颗LED。

## 10. ESP32物联网时钟/游戏机

### 项目概要
基于ESP32的多功能设备：TFT屏显示+音频功放+锂电池充电。

### 核心设计
- ESP32一键自动下载电路：CH340C + 2个三极管控制EN和IO0。
- 锂电池充电：TP4056（自带过充/过放保护，充电中红灯/充满绿灯）。
- 音频功放：FM8002A（外围极简、关断引脚低功耗、旁路电容推荐1μF）。
- 开发环境：Linux虚拟机(Ubuntu) + ESP-IDF + VS Code。

## 通用设计流程（所有项目适用）

```
器件选型 → 原理图绘制 → 元器件布局 → PCB走线 → 铺铜 → DRC检查 → 丝印优化 → PCB下单
```

### 阶段一：方案设计
- 参考本文档找到类似项目 → 对照调整需求 → 确定选型清单。

### 阶段二：原理图设计
- 查阅 `schematic-rules.md` 了解原理图规范和DRC规则。
- 分图页绘制大型工程，使用跨页连接标识。
- 差分对命名遵循 _P/_N 或 _DP/_DN 规则。
- 使用非连接标识符（红叉）处理未使用引脚。

### 阶段三：PCB设计
- 查阅 `pcb-design-rules.md` 了解布局布线规则。
- 布局传递（Ctrl+Shift+X）：原理图框选→PCB对应选中。
- 元件区域分布（Shift+P）：批量自动排布。
- 信号流向布局：按原理图信号走向排列（如左进右出）。

### 阶段四：打样与调试
- PCB下单前必须运行DRC检查。
- 嘉立创两层板最小线宽/线距4mil。
- 铺铜到导线/焊盘的默认间距10mil。
