# 电子方案分析

根据用户需求，系统性地完成电子项目方案分析，输出可执行的设计文档。

## 模式判断

分析前先判断工作模式：

- **方案分析模式（默认）**：用户提出需求/想法，需要从头设计方案。按完整五步流程执行。
- **审查模式**：用户已有工程/电路图，仅需要分析评审。只做分析不改动，针对用户工程输出：技术亮点、潜在风险、优化建议。

## 一、设计流程

### Step 1：需求澄清

**目标**：将模糊的项目想法转化为清晰的工程设计规格。

**引导问题（按优先级依次确认）**：

1. **功能需求** —— 产品需要实现哪些具体功能？将所有功能逐一列出，然后按以下维度归类合并：
   - 将看似复杂的多项需求归并为几个核心功能模块。例如"逻辑电平检测 + 通断检测 + 点亮LED + 信号源输出 + 模拟电平输出"可归为三个核心：电压输入检测(ADC)、信号输出(DAC)、电流源。
   - 区分必选功能和扩展功能。先保证核心功能完整，再在此基础上增加扩展。

2. **性能指标** —— 每个核心功能需要达到什么性能水平？重点明确以下参数：
   - **模拟采集**：分辨率（ADC位数）、采样率（需大于被测量信号最高频率的2倍，推荐10倍以上）、输入电压范围、参考电压精度。
   - **电机驱动**：转速、扭矩、是否带编码器反馈、供电电压、体积约束（如N20微型电机）。
   - **信号处理**：增益带宽积（增益与带宽乘积固定）、压摆率（处理高速信号需充分考虑）、轨对轨特性（单电源场景关注输出轨）、失调电压（精密小信号放大需选低失调电压运放）。
   - **通信速率**：数据吞吐量、实时性要求、传输距离。

3. **约束条件** —— 逐一确认以下约束：
   - **成本**：单片BOM预算范围？是否接受国产替代？减少物料种类可降低BOM和SMT成本（如用两颗已有料号的10K串联替代一颗20K新料号）。
   - **体积**：产品物理尺寸限制？是否必须使用特定封装？小体积场景（如测试笔）应选用固态继电器代替传统继电器。
   - **功耗**：电池供电还是外部供电？待机功耗要求？LDO等低效率器件应放在电源开关之后以降低待机功耗。
   - **可靠性**：是否需要电气隔离（高压测量场景应用BLE无线通信隔离）？是否需要输入保护（钳位二极管+限流电阻）？

**完成标准**：产出一份功能列表（标注必选/可选）、每项功能的性能指标数值、明确的约束条件清单。

### Step 2：方案选型

**目标**：为核心模块逐一确定器件方案。

按以下优先级依次做选型决策：**主控 → 电源 → 通信 → 关键外设**。

#### 2.1 主控MCU/MPU选型

**决策流程**：
```
需求分析 → 统计所需外设种类与数量 → 确定IO数量 → 评估处理能力需求
→ 查阅候选芯片数据手册（产品简介→电气属性→引脚封装）→ 做项目评估 → 确定选型
```

**关键考量**：
- 先列出所有需要的外设（GPIO、UART、SPI、I2C、定时器/PWM、ADC、DAC、USB、CAN等），按实际需求匹配芯片资源。
- 信号处理类题目（如仪器仪表测量、示波器）推荐功能较强的MCU如STM32H7/F4系列。
- 联网项目优先考虑ESP32系列（内置WiFi/BLE）。
- 电机控制类项目关注定时器通道数、死区控制能力（如GD32F450）。
- 低成本/简单控制项目可用国产替代（HK32F103兼容STM32F103引脚、CW32F030）。
- 选型前列数据手册优先核对：产品简介→电气属性表→引脚封装图→外设数量。

**典型场景参考**（详见 `references/mcu-selection.md`）：
| 场景 | 推荐方案 | 关键理由 |
|------|---------|---------|
| 智能小车/电机控制 | GD32F450 / STM32F103 | 多路定时器PWM、接口丰富 |
| WIFI联网控制 | ESP32-C3 / ESP32-S3 | 内置WIFI+BLE、低成本 |
| 仪器仪表/信号测量 | STM32H750 / STM32F407 | 高速ADC、DSP指令 |
| 简单IO控制/低成本 | CW32F030 / HK32F103 | 国产低功耗、价格低 |
| USB下载器/调试器 | AT32F425 | USB外设完善 |

#### 2.2 电源方案选型

使用电源决策树（详见 `references/power-topology.md`）：

**一级判断：输入输出关系**
- 降压（Vin > Vout）→ Buck（如7.4V锂电池降压到5V/3.3V）
- 升压（Vin < Vout）→ Boost（如3.7V锂电池升压到5V/12V）
- 升降压（Vin可能高于或低于Vout）→ 四开关Buck-Boost

**二级判断：LDO vs DC/DC**
| 特性 | LDO | DC/DC（开关电源） |
|------|-----|------------------|
| 效率 | 低（压差大时发热严重） | 高（通常85%~95%） |
| 纹波 | 低、干净 | 较高，需滤波 |
| 占板面积 | 小 | 较大（需电感、电容） |
| 适用场景 | 小电流（<500mA）、压差小的场景 | 大电流、压差大的场景 |

**选型规则**：
- MCU供电（3.3V）：小电流场景用LDO（如AMS1117-3.3），注意压差要求——低压差LDO才能在锂电池（3.7V~4.2V）场景可靠输出3.3V。
- 电机/功率器件供电：直接用电池供电，不经LDO，避免LDO过热。
- 电池供电设备：待机通路上的LDO放在MOS管之后，避免静态电流消耗。
- 模拟/数字混合电路：用磁珠分隔AGND和DGND，单点接地防止噪声串扰。

**DCDC芯片选型速查**（规格书阅读优先关注项）：
1. 上下管导通阻抗（Rds(on)）—— 决定导通损耗和发热
2. 开关频率（fsw）—— 影响电感体积和开关损耗
3. 电流限值 —— 不等于输出电流，应留足余量（Ipk=Iout+0.5×ΔIL）
4. 静态电流 —— 不是待机电流，仅逻辑电路工作的电流
5. EN开启阈值与迟滞 —— 避免在阈值附近反复开关

#### 2.3 通信方案选型

使用通信决策树（详见 `references/communication.md`）：

**有线通信**：
- **USB**（Type-C）：供电+数据二合一，适合与电脑通信的桌面设备。高压测量场景下USB直连电脑存在安全风险，应加隔离或改用无线。
- **UART**：点对点低速通信，常用于蓝牙模块、GPS模块、调试串口。
- **SPI**：高速全双工，常用于TFT屏、Flash、高速ADC。
- **I2C**：多器件共享双线总线（需外接上拉电阻，典型值4.7KΩ），常用于传感器、RTC、OLED屏。
- **CAN/RS485**：工业环境、长距离、差分信号抗干扰。

**无线通信**：
- **蓝牙BLE**：短距离（10m）、低功耗、手机直连，适合遥控/数传/传感器节点。
- **WiFi**：高速率、可联网、云平台接入（如ESP32+MQTT连接巴法云），适合智能家居/远程控制。
- **2.4G私有协议**：比蓝牙延迟更低、更稳定，适合遥控竞速类项目。
- **NB-IoT/LoRa**：远距离低功耗物联网，适合户外定位/环境监测。

**选型规则**：
- 高压/隔离场景 → 优先无线（BLE），避免电气连接风险。
- 实时控制场景 → 2.4G私有协议（延迟低）或CAN总线。
- 需要联网/云平台 → WiFi + MQTT。
- 多传感器低速采集 → I2C总线串接。

#### 2.4 关键外设选型

**电机驱动**：
- 有刷直流电机：H桥驱动芯片（如RZ7899，外围简单，电池直供），每路两个控制引脚控制正转/反转/刹车/滑行。
- 无刷直流电机：三相桥式MOS管驱动（6路PWM→栅极驱动芯片→6颗MOSFET），或集成方案（如DRV8870，支持正反转，最大3.6A/45V）。
- 电机两端并联104电容（焊在电机端子上而非PCB上，厂家建议）。
- 选型关键参数：转速（目标速度换算，轮径×π×转速/60 = 线速度）、堵转电流。

**传感器**：
- 循迹：红外对管（TCRT5000）+ LM393比较器 + 滑动变阻器调灵敏度。数字型简单但只有高低电平；模拟型（ADC采集）可读取灰度等级但程序更复杂。
- 超声波测距：HC-SR04（3V~5.5V供电、最大6m、精度3mm），Trig触发10us高电平→ECHO回响高电平时间与距离成正比。
- 姿态感知：MPU6050陀螺仪（I2C接口）。

**显示与交互**：
- 小型显示：0.96寸OLED（I2C/SPI，128x64）。
- 彩色显示：TFT LCD（SPI，需合理分配引脚）。
- 按键：GPIO输入上拉/下拉检测；多按键可用ADC按键（不同分压值区分）。

**完成标准**：产出一份选型决策表，包含：模块名称、选定器件型号、选型理由、备选方案、关键参数。

### Step 3：系统架构

**目标**：绘制系统框图，明确模块间接口。

**3.1 模块划分**

按功能将系统拆分为独立模块，每个模块职责单一。典型分层：
```
应用层（显示/交互/算法）
   ↕
控制层（MCU主控 + 固件逻辑）
   ↕
接口层（GPIO/UART/SPI/I2C/ADC/PWM）
   ↕
硬件层（电源/传感器/驱动/通信模块）
```

**3.2 接口定义**

为每个模块间连接定义：
- **电气接口**：电压等级（3.3V/5V/12V）、信号类型（数字/模拟/PWM）、是否需要电平转换。
- **通信协议**：UART（波特率）、SPI（模式/速率）、I2C（地址/速率）。
- **引脚分配**：遵循以下原则 ——
  - 优先使用硬件外设默认引脚（复用功能AF）。
  - 同组功能引脚集中分配（如四路PWM用同一定时器的连续通道）。
  - 预留调试串口和SWD下载口。
  - 模拟信号引脚远离高速数字信号引脚。

示例（智能小车梁山派GD32F450引脚分配）：
| 功能 | 引脚 | 复用 | 说明 |
|------|------|------|------|
| 左前轮前进 | PB4 | TIM2_CH0, AF2 | 与其余三路共用一个定时器 |
| ADC电量检测 | PC5 | ADC01_CH15 | 2:1电阻分压输入 |

**3.3 数据流**

描述系统工作时数据如何流动：
- 传感器 → MCU采集（ADC/DMA/中断）→ 数据处理（滤波/算法）→ 控制输出（PWM/GPIO）→ 执行器
- 标注每段数据流的带宽、延迟、采样率要求。

**3.4 供电架构**

绘制电源树，从输入到各模块的供电链路：
```
电池(7.4V) ┬─→ 电机驱动芯片（直供，不经LDO）
            ├─→ 5V Buck DCDC ─→ 舵机/传感器(5V)
            └─→ 3.3V LDO ─→ MCU / 蓝牙 / OLED(3.3V)
```

**完成标准**：系统框图（含模块划分和接口标注）、引脚分配表、电源树、数据流描述。

### Step 4：可行性评估

**目标**：识别风险、估算成本和周期。

**4.1 技术风险评估**

逐项检查以下高风险点：
- [ ] 是否有未使用过的芯片/模块？→ 提前申请样品、阅读数据手册和勘误表。
- [ ] 是否有高频/高速信号？→ 评估PCB布局难度、是否需要阻抗匹配。
- [ ] 是否有模拟小信号？→ 评估运放选型是否满足精度/带宽/噪声要求。
- [ ] 是否有高压/大电流？→ 检查隔离和保护电路设计。
- [ ] 是否有严格的实时性要求？→ 确认MCU中断响应时间和定时器资源。
- [ ] 晶振选型是否与MCU兼容？→ 必须查阅数据手册：某些MCU仅支持低速无源晶振+高速有源晶振（如STM32G0 K6T6）。
- [ ] DCDC电感饱和电流和额定电流是否满足要求？

**4.2 成本估算**

- 主控芯片 + 关键器件 + PCB + 接插件 + 外壳 = 总BOM估算。
- 考虑物料种类数：用已有料号替代新料号可降低管理和SMT成本。
- 嘉立创贴片：确认元器件是否为嘉立创基础库/扩展库，非库存器件需自行购买。

**4.3 开发周期评估**

按阶段估算：
- 方案设计+选型：1~3天
- 原理图绘制：1~5天（按复杂度）
- PCB Layout：1~5天
- 打样+焊接：5~10天（嘉立创PCB打样周期）
- 固件开发+调试：视复杂度而定
- 整机联调：预留足够buffer

**完成标准**：风险清单（标注概率和影响）、BOM成本预算、开发甘特图。

## 三、设计规则速查

以下为核心选型决策表，详细内容见 `references/` 目录下的对应文件。

### 3.1 MCU选型速查

**详细表格见** `references/mcu-selection.md`

快速匹配：
- 需要**WIFI联网** → ESP32系列（ESP32-C3/S3）
- 需要**高性能ADC/信号处理** → STM32H7 / STM32F4 系列
- 需要**多路电机PWM** → GD32F450 / STM32F103
- 需要**低功耗/小体积** → CW32F030 / STM32L0 系列
- 需要**USB通信+下载器** → AT32F425
- 需要**低成本替代STM32** → HK32F103C8T6（引脚兼容）

### 3.2 电源方案决策树

**详细内容见** `references/power-topology.md`

核心判断路径：
```
输入电压 > 输出电压？ → 是 → 电流>500mA或压差>2V？ → 是 → Buck DCDC
                      → 否 → LDO
                      否 → 输入电压 < 输出电压？ → Boost DCDC
                      → 输入可能高于也可能低于输出 → 四开关Buck-Boost
```

### 3.3 通信方案决策树

**详细内容见** `references/communication.md`

核心判断路径：
```
需要联网/云平台？ → WiFi (ESP32 + MQTT)
需要手机直连？ → BLE蓝牙
需要低延迟遥控？ → 2.4G私有协议
多板卡间通信？ → CAN / RS485
传感器采集（低速多节点）？ → I2C
高速外设（屏/Flash）？ → SPI
调试/模块连接？ → UART
```

### 3.4 PCB叠层结构与图层体系 [来源：Expert入门篇 P9-P10]

**物理结构**：PCB类比三明治——PP半固化片 + 芯板（玻璃纤维+固态树脂）+ 铜箔。覆铜板结构为铜箔层 / 固态树脂 / 玻璃纤维。

**多层板典型叠层**：
- 四层板：顶层信号 / 电源层 / 地层 / 底层信号
- 六层板：信号 / 地 / 信号 / 电源 / 地 / 信号

**嘉立创EDA图层体系**：
| 类别 | 图层 | 功能 |
|------|------|------|
| 导电层 | 顶层(Top)红色 / 底层(Bottom)蓝色 | 信号走线 |
| 导电层 | 多层(Multi-Layer)灰色 | 过孔（贯穿所有层） |
| 丝印层 | 顶层丝印黄色 / 底层丝印绿色 | 元件参数/logo |
| 阻焊层 | 深紫色 | 开窗区域（比焊盘略大） |
| 辅助层 | 锡膏层 | 钢网开孔依据 |
| 辅助层 | 机械层 | 外形尺寸/装配注释（不在成品板上体现） |
| 辅助层 | 板框层浅紫色 | 板子外形定义 |
| 特殊层 | 3D外壳层 | 立创EDA特色功能，快速建模3D外壳 |

**过孔类型**：
- 通孔(Through Hole)：从顶层贯穿到底层
- 盲孔(Blind Via)：从顶层或底层到中间某层停止（工艺贵）
- 埋孔(Buried Via)：起点终点都在内层，PCB表面不可见（工艺贵）

**PCB板上物理元素**：
- 导线：细铜箔连接不同元件引脚
- 铺铜(Copper Pour)：大面积铜皮，通常用于GND和电源网络
- 十字连接（热焊盘）：防止焊接时铜皮散热太快导致虚焊
- 填充(Fill/直连)：用于过大电流场景（需大功率烙铁焊接）
- 焊盘：表贴式（无孔）、通孔式（有孔）
- 丝印：PCB表面的白色文字/logo
- 阻焊：覆盖在铜层上的油墨，保护铜层、防止焊接短路

### 3.5 嘉立创免费打样规则 [来源：Expert入门篇 P12]

- 每月2次免费打样机会
- 板子尺寸控制在10×10cm以内（99×99mm更稳妥）
- 1~4层板免费

## 四、审查模式（仅分析不改动）

当用户提供已有工程/电路图要求分析时，按以下框架评审：

### 评审清单

**原理图层面**：
- [ ] DRC检查通过？错误（红色）必须清零，警告（黄色）需逐一核实。
- [ ] 网络标签是否正确连接？检查游离标签（未放在导线/引脚上）。
- [ ] 同一导线是否误放了多个不同名称的网络标签？（应使用短接标识符替代）
- [ ] 未使用引脚是否放置了非连接标识符（红叉）？
- [ ] 差分对命名是否符合 _P/_N 或 _DP/_DN 规则？
- [ ] 晶振选型是否与MCU数据手册兼容？
- [ ] 引脚复用功能是否冲突？

**PCB层面**：
- [ ] DRC检查通过？最小线宽/线距不应小于板厂工艺极限（嘉立创两层板为4mil）。
- [ ] 晶振布局：靠近MCU、负载电容靠近晶振、下方不走线、远离板边、周围禁止铺铜区。
- [ ] 滤波电容是否就近器件摆放？
- [ ] 电源走线是否足够宽？是否分配了独立的电源线宽规则（如10mil最小/20mil默认）？
- [ ] DCDC输入电容是否靠近芯片Vin和GND引脚？（否则线路寄生电感引起输入电压尖峰）
- [ ] 模拟地与数字地是否用磁珠/0Ω电阻单点接地？
- [ ] 缝合孔/回流孔是否在铺铜区域充分放置？

**方案层面**：
- [ ] 关键器件选型是否有数据手册支撑？
- [ ] 电源方案是否满足各模块供电需求？
- [ ] 输入保护/隔离措施是否充分？
- [ ] 是否有明显的热设计问题（如LDO压差过大发热严重）？

### 输出格式

仅做分析不改动，输出：
1. **技术亮点**：当前设计做得好的地方。
2. **潜在风险**：按严重程度排序的问题清单。
3. **优化建议**：每条建议附带具体理由和可行方案。

## 六、元件选型与读值方法 [新增，来源：Expert入门篇 P4-P5]

以下内容为PCB设计中工程师必备的元件辨识与选型基础知识，嘉立创EDA操作教程中通常不涉及。

### 6.1 电阻读值

**色环电阻（插件）**：
- 四环：前两环=数值，第三环=倍率(10^n)，第四环=误差（金=±5%）
- 五环：前三环=数值，第四环=倍率，第五环=误差（棕=±1%）

**贴片电阻（三位数标记，精度±5%）**：
- 前两位有效+第三位10^n。例：104=10×10^4=100K

**贴片电阻（四位数标记，精度±1%）**：
- 前三位有效+第四位10^n。例：5112=511×10^2=51.1K

**R标记法**：R=小数点。例：R006=0.006Ω, R003=0.003Ω

**封装与功率对应**：0805/0603/0402等不同封装对应不同额定功率，选型时需注意功率余量。

**特殊类型**：排阻、功率电阻、滑动变阻器、光敏电阻。

### 6.2 电容读值与选型

**电容核心特性**：储能元件，通交流隔直流。电压电流关系为积分形式 `U = 1/C ∫i dt`。

**类型与选型**：
| 类型 | 特点 | 适用场景 |
|------|------|---------|
| MLCC（陶瓷电容） | 中高频段滤波好，容值偏低 | 去耦、高频滤波 |
| 钽电容/铝电解 | 容值比MLCC高 | 中低频段滤波 |
| 多类型并联 | 1+1>2滤波效果 | 电源输入/输出端 |

**关键设计警告**：钽电容和铝电解电容有极性，接反可能爆炸。

**读值方法**：
- 插件铝电解：白色竖线=负极；容值直接印在封装上（如470μF 35V），默认单位μF
- 贴片铝电解：黑色小半圆=负极；容值印在顶层丝印
- 钽电容（小体积三位数标法）：同贴片电阻（226=22×10^6pF=22μF），**单位pF注意！**；字母V对照表查耐压（如V=35V）；杠杠侧=正极性（与铝电解相反！）
- X电容：封装上直接标注（0.01μF 275V）
- CBB电容：同钽电容三位数读法（684=68×10^4pF=0.68μF）
- 瓷片电容：无耐压标注时默认50V
- 涤纶电容：如2A223G→223=22×10^3pF=0.022μF；G=±5%；2A查耐压表（A=1V, 2=10^2，即100V耐压）

### 6.3 电感读值与选型

**核心特性**：储能元件（动态元件）；通直流阻交流；电压电流关系为微分形式 `U = L × di/dt`。

**功能**：滤波、扼流、谐振、储能。

**类型**：贴片功率电感、磁片电感、工字电感、磁棒电感、环形电感、共模电感（4引脚）。

**读值**：色环电感同色环电阻；贴片功率电感同贴片电阻（331=33×10^1=330μH）；1R5=1.5μH。

**DCDC电感选型关键** [来源：RYDZ智能车板]：
- 务必使用**一体成型电感**（屏蔽式），不要用开放式电感（磁芯裸露在外）
- 开放式电感有磁通量泄漏，会产生电磁干扰导致"莫名其妙的问题"
- 一体成型电感下方不需要设置禁止铺铜区；开放式电感下方必须设置
- 电感额定电流需大于芯片输出电流（留50%余量，如3A输出→选4.5A额定电感）

### 6.4 半导体器件选型要点 [来源：Expert入门篇 P5]

**二极管**：
- 核心特性：单向导电性，电流从阳极→阴极
- 应用分类：
  | 类型 | 典型应用 |
  |------|----------|
  | 普通二极管 | 整流 |
  | 稳压二极管 | 电压基准/稳压 |
  | 发光二极管(LED) | 指示/照明 |
  | 肖特基二极管 | 防反接（低压降低至0.2-0.3V）、DCDC续流 |
  | TVS管 | ESD/浪涌保护 |
- 正负极识别：贴片二极管(SOD-323等)浅色竖线端=负极；插件二极管黑色竖线端=负极；LED灯珠"大红旗"=负极、引脚短=负

**三极管（BJT）**：
- NPN vs PNP判断："箭头由P指向N"→箭头向外=NPN
- 三个区：截止区（开关断开）、放大区（IC=β×IB）、饱和区（开关闭合，CE间近似短路）
- 应用：单片机IO口驱动力不足时用三极管放大驱动负载

**场效应管（MOSFET）**：
- 与三极管对比：三极管为电流控制(IB)，MOSFET为电压控制(UGS)
- 封装与功率选型：
  | 封装 | 电流/电压等级 | 典型场景 |
  |------|-------------|---------|
  | SOT-23 | 几A、60V以下 | 单片机IO口控制 |
  | TO-252 | 可达70A、100V以内 | 中等功率 |
  | TO-220/TO-263 | 大功率 | 电机驱动（带散热孔/散热焊盘） |

## 七、数据手册阅读方法论 [新增，来源：Expert入门篇 P6]

这是从"会用工具画板"到"理解电路设计"的关键桥梁。嘉立创EDA操作教程中不涉及系统的Datasheet教学方法。

### 7.1 获取途径

- **立创商城**（推荐首选）：品种齐全，对应库中有则商城有
- **半导小芯**：专业查手册网站，无广告
- **原厂官网**：如STC官网、TI官网

### 7.2 11部分阅读框架（以TPS5450为例）

| 优先级 | 部分 | 阅读要点 |
|--------|------|----------|
| **极高** | 引脚配置和功能 | 引脚图、引脚功能表格（名称/编号/I-O类型/说明），设计原理图的核心依据 |
| **极高** | 应用和实现 | 典型应用电路+外围器件选型公式（代入自身参数计算），**设计的直接依据** |
| **高** | 特性(Features) | 芯片优点集中展示：输入电压范围、输出电流、效率、保护措施；**用于快速选型** |
| **高** | 应用(Applications) | 适用场景列表+参考示例电路图 |
| **高** | 规格(Specifications) | 电气特性表格（最小值/典型值/最大值）、ESD等级、建议工作条件 |
| **中** | 说明(Description) | 对特性的补充描述 |
| **中** | 详细说明 | 功能框图+特性说明，理解芯片内部工作原理 |
| **按需** | PCB布局建议 | 如芯片对布局布线有特殊要求，必须遵守 |
| **按需** | 机械封装和可订购信息 | 无现成封装时按机械图自行绘制封装 |
| **跳过** | 修订历史 | 不关注 |
| **跳过** | 器件和文档支持 | 不关注 |

### 7.3 核心方法论（三精华点）

1. **引脚图+引脚功能表格** → 理解芯片做什么
2. **电气特性表格** → 确认设计不越界（不突破电气限制）
3. **典型应用+选型公式** → 完成外围电路设计（代入自身参数计算）

**工程实践心法**：
- 不需要把数据手册每一条都搞明白（10~100+页，含英文）
- 区分关键信息与可忽略信息
- "电路设计不意味着每个电路结构都自己从零设计"——参考厂家示例电路，在示例电路基础上结合自身应用场景修改
- 厂家示例电路可靠性高，按公式选型成功率大
- **选型决策链**：每个外围元件选择都要回到芯片数据手册的推荐电路和电气参数

**给初学者的两条建议**：
1. "多读多练，当成小说读"：不管熟悉不熟悉，有空就下载下来读
2. 学好英语（大部分芯片厂商为国外厂商，数据手册为英文）；不会的可以截图发给AI辅助分析

## 八、原理图工程化设计 [新增，来源：Expert入门篇 P7-P8]

以下工程方法论是复杂项目原理图设计的高级技巧，嘉立创EDA操作教程中极少涉及。

### 8.1 原理图阅读五步法

1. **先看右下角标题栏**：软件logo、作者、标题（知道板子做什么）、创建/更新日期、页码
2. **分模块观察**：利用注释框识别各个功能模块（电源、MCU最小系统、接口、驱动等）
3. **逐模块分析**：找到模块中每个芯片→查数据手册→对照引脚功能说明和示例电路理解连接
4. **对照数据手册示例电路**：大部分实际电路 = 数据手册示例电路 + 场景适配修改
5. **综合理解**：不只用电路定理死板分析，结合数据手册功能说明效率更高

### 8.2 原理图绘制规范（"规范、清晰、准确、易读"四原则）

| 规范 | 具体做法 |
|------|----------|
| 分模块布局 | 电源左上、MCU右上、按键左下、显示右下 |
| 分图页 | 复杂设计一页一功能；前面几页放系统框图+电源树+GPIO分配表 |
| 标注重要参数 | 无法从符号直接读取的参数必须标注（如LDO最大输出电流1A） |
| 注意事项标注 | 启动引脚电平要求、NC(不连接)、NM/NF(不安装)、0R(0Ω电阻=短路用) |
| 合理网络标签 | 格式：`元件名_信号功能`（如MPU6050_SDA）；避免重复 |
| 标注logo/版本号 | 便于后续对照修改 |

### 8.3 工程化设计文档

在绘制原理图之前，应先完成以下三项工程文档：

**系统框图(System Diagram)**：
- 描述功能模块及模块间通信方式（如I2C/SPI/UART）
- 帮助全局把握设计，避免遗漏功能

**电源树(Power Diagram)**：
- 描述各路电源如何产生和分配（从输入到各模块的电压转换链路）
- 示例：`电池12V → DCDC 5V → LDO 3.3V → MCU`
- 标注每路电源的电流需求和电压容差

**GPIO分配表**：
- 多引脚主控的引脚功能规划
- 标注复用功能、信号方向、电平标准
- 先规划好再画原理图，避免后期引脚冲突推倒重来

**电源上电时序** [来源：Expert入门篇 P8]：对复杂系统有严格要求，不满足可能导致芯片死锁。需在电源树中标注各电源轨的上电顺序。

**分图页案例**：正点原子开发板分23个图页，前3页为系统框图/电源树/GPIO分配。

## 九、PCB设计进阶技巧 [新增]

以下技巧来自多个实战项目的经验总结，补充已有参考文件（`references/pcb-design-rules.md`）中未覆盖的深层知识。

### 9.1 布局进阶原则

**蓝桥杯EDA竞赛级布局标准（三层要求）** [来源：Expert强化篇 P21]：
1. **整齐美观**：元器件之间相互平行或垂直排列，不横竖混放
2. **分布均匀**：排列紧凑，疏密一致，避免大片空白，充分利用板子有效空间
3. **顶层优先**（竞赛要求）：实际DIY可忽略——手动焊接顶层底层无区别；大批量生产放顶层方便回流焊

**补充三项布局原则** [来源：Expert强化篇 P21 + RYDZ智能车板]：
- **根据电气特性和使用特点布局**：接口/按键/排针→板子边缘；屏幕/主控→板子中央；电源电路→电源输入旁边，注意电流路径；晶振→尽量贴近单片机
- **考虑元器件三维高度**：PCB是二维平面画图，但不能忽略元件高度——屏幕下方不能放高元件
- **模块化布局**：同一功能电路放在同一区域，方便布线和调试

**布局顺序（优先级从高到低）** [来源：RYDZ智能车板]：
1. 先放固定位置的件：螺丝孔（根据安装底板尺寸精确放置）、主控板（烧录口朝向板边）、电机接口（靠近驱动模块）
2. 再放大尺寸模块：稳压模块、驱动模块、OLED屏幕
3. 最后放置离散元件：滤波电容放在对应电源引脚旁（越近滤波效果越好）、按键放在板边、电位器旋钮伸出板边
4. 板子尺寸控制在99×99mm以内以符合嘉立创免费打样规则

**布局快捷键与技巧** [来源：Expert强化篇 P21]：
- `Shift+X`：交叉选择——在原理图和PCB之间快速定位对应元件
- `Ctrl+Shift+X`：布局传递——原理图布局结构自动映射到PCB
- **先预布局后上板**：先在PCB空白区域按模块预布局各组电路，再整体拖入板框内
- **隐藏GND飞线**：布局阶段GND飞线干扰视线，可暂时关闭GND网络飞线

**器件布局具体规则** [来源：Expert强化篇 P21]：
- Type-C → 板边 → 开关 → LDO（沿电流流向）
- 滤波电容：先大后小（大电容远离芯片，小电容贴近引脚）
- 晶振紧贴单片机晶振引脚，保持轴对称（便于差分等长布线）
- 按键保持同向放置、疏密一致

### 9.2 布线策略与优先级 [来源：Expert强化篇 P22-P23 + MSPM0 + 智能车]

**布线优先级（按信号重要程度从高到低）**：
1. **差分信号线**（USB、晶振等）
2. **GPIO信号线**（从单片机引出到排针）
3. **晶振线**（高速信号，差分对等长处理）
4. **外围功能电路信号线**（按键、LED、复位等）
5. **电源线**（加粗处理）
6. **GND网络**（通过铺铜+过孔解决）

**信号线布线规则**：
- 线宽：默认8~10mil（信号线）
- 走线方式：横平竖直，禁止大面积斜线；拐弯用135度角，**禁止90度直角**（直角等效于贴片天线辐射电磁能量）
- **焊盘短边出线原则** [来源：Expert强化篇]：从焊盘短边引出，不从长边出（长边出会形成两个直角）
- 能走顶层就不打过孔：顶层能布通则不走底层，避免底层走线混乱
- 间距：多条信号线保持等间距，美观工整
- 元件内部不走线：原则上不穿过元件内部走线

**电源线布线规则** [来源：Expert强化篇 P22-P23 + MSPM0]：
| 线类型 | 线宽 | 说明 |
|--------|------|------|
| 普通信号线 | 8~10mil | 常规IO、低速信号 |
| 芯片滤波电容到引脚 | 12mil | 略宽 |
| 普通电源线（3.3V/5V分支） | 20mil | 非主供电通路 |
| 主电源走线（LDO输出） | 30~40mil | 承载较大电流 |
| 主电源干路 | 50~60mil | 主供电干路 |
| 使能引脚/上拉 | 20mil | 不过大电流 |

**线宽确定方法**：先查看目标焊盘宽度，线宽不超过焊盘宽度以避免DRC报错。

**取电位置**：必须从滤波电容**之后**取电，不从未滤波端取电。

**布线顺序技巧**：电源先经过大电容再经过小电容（先大后小滤波），然后送入芯片。

**多路布线** [来源：RYDZ MSPM0系列]：选中多根同方向走线可一次性拉出（快捷键波浪线），大幅提高效率。

**实心填充法** [来源：Expert强化篇 USB拓展坞]：使用"实心填充（多边形）"替代普通导线走电源网络，整块铜皮的过流能力远优于导线。配合多个过孔并联增强过流能力（如3个过孔，外径24mil/内径12mil）。

**布局为布线让路** [来源：Expert强化篇 P22]：布线过程中发现问题应主动调换元件位置，不是死守布局。

### 9.3 差分信号理论与布线规则 [来源：Expert强化篇 USB拓展坞]

**单端信号 vs 差分信号**：
- 单端信号依赖参考地平面（如UART TX/RX相对于GND），噪声直接叠加到有效信号，抗干扰能力差、传输距离短
- 差分信号通过两根极性相反的信号线的电压差传输，接收端取(V+)-(V-)，共模噪声被抵消

**差分线7条设计规则（具体数值）**：
1. 差分线尽量短
2. 优先绘制差分线
3. 差分线上不超过2对过孔
4. 平行紧密走线，避免直角和锐角
5. **线长差控制在5mil以内**（在立创EDA差分对规则中设置）
6. 与其他信号网络及GND间距>20mil
7. USB差分阻抗为90Ω（入门阶段可不严格考虑，但高频设计必须处理）

**差分对布线操作流程** [来源：Expert强化篇 USB拓展坞]：
1. 设计规则中设置差分对内误差为5mil
2. 工程设计中添加差分对（Alt+D快捷键呼出）
3. 差分对等长调节：选中较短线，使用"等长调节"进行蛇形走线（框选区域后软件自动生成）

### 9.4 晶振电路处理 [来源：Expert强化篇 P22-P23 + MSPM0]

**晶振外围屏蔽（via fence + keepout复合处理）**：
1. 晶振外围打一圈GND过孔（外径24mil/内径12mil），形成电磁屏蔽环
2. 用20mil粗线将这些GND过孔串联
3. 放置**禁止铺铜区**（多层禁止区域），防止铺铜铺到晶振电路上
4. 禁止区域内侧用GND过孔包围，外侧与外部铺铜形成清晰分界线

**晶振差分对布线** [来源：Expert强化篇 P22]：
- 晶振两路信号线定义为差分对（Alt+D），软件自动检查等长
- 布局上保持轴对称→自动实现等长
- 长度差控制在10mil以内（绿色提示为合格）

**晶振布局铁律**：
- 负载电容先于晶振：走线先经过负载电容再进入晶振
- 晶振下方所有层禁止铺铜（顶层+底层）
- 走线不要从晶振下方穿过
- 晶振不能完全贴在板边，防止电磁信号外泄
- 走线尽量短，靠近芯片；最好不要打过孔

**有源 vs 无源晶振选择**：
- 下载器/通信设备等对时钟精度要求高的场景 → 有源晶振（仅接OSC_IN，稳定性好）
- 常规MCU场景 → 无源晶振（需两个负载电容，节省成本）

### 9.5 铺铜与过孔策略 [来源：Expert强化篇 P23 + MSPM0 + 智能车]

**铺铜规范**：
- 顶层和底层均铺GND铜
- 铺铜连接方式：推荐"发散"（十字连接/热焊盘），线宽10mil，间距10mil，90度。选择"直连"则焊接需要大功率烙铁
- 铺铜后检查信号线周围空白区域，放GND过孔后**重建铺铜**可填补空白
- 信号线周围包一圈铜皮→保护信号完整性

**地平面与过孔**：
- 底层做完整地平面
- 顶层GND孤岛通过打过孔连接到底层地平面
- 芯片散热焊盘（EP/GND）下方多打过孔到地平面，增强散热
- GND过孔（缝合孔）不要怕多——机器打孔很快，多放无妨
- 在空白区域打GND缝合孔能增加电流路径、增强载流能力、改善EMI

**缝合孔自动放置** [来源：RYDZ MSPM0系列]：
- 铺铜后使用"放置/移除缝合孔"功能自动打地过孔
- 参数：外径24mil、内径12mil、行距80mil、列距80mil（或用30mil更密）
- 对未铺上铜的孤岛区域，手动补打过孔

**泪滴添加规范流程** [来源：MSPM0 + Expert强化篇]：
1. 铺铜完成 → 工具→放置泪滴 → 重建铺铜 → DRC检查
2. 顺序不可乱，否则DRC报错
3. 可在设置→PCB→通用→布线中勾选"自动添加泪滴"

### 9.6 丝印工程化设计 [来源：Expert强化篇 P24 + MSPM0 + 智能车]

**丝印内容规划**：
- 正面：IO口旁标注引脚名（如A14、PA25），电源引脚标注5V/3V3/GND；画框线分隔各组引脚；横杠分上下行，竖杠分左右列
- 背面：板子名称和引脚数、引脚定义表（如LED1=PB0）、按键功能标注、店铺/学校/个人信息
- 开关方向标识：在"开"方向放小圆点（半径10mil圆形）

**字体与尺寸**：
- 推荐字体：嘉立创EDA中以"A"开头的某字体
- 引脚标注高度：60mil（正面）、50mil（背面可略小）
- 板名标题高度：80~120mil
- 线宽：5mil（引脚标注）

**高效操作技巧**：
- 丝印对齐：先确定首尾两个丝印位置→框选整列→右对齐+垂直等间距→自动排列
- 可用左对齐/右对齐/顶部对齐快速规整
- 布线时将丝印层隐藏，避免干扰
- 正面丝印画好后，复制一份改为底层丝印层做背面
- 放置图片功能导入logo（容差/简化参数控制线稿质量）

**丝印注意事项**：
- 丝印要离焊盘一定距离（>1mm），否则排针/排母焊上后会遮挡文字
- 用3D预览反复检查丝印是否有越界、重叠、字体不一致等问题
- 丝印即"硬件注释"——给队友的文档，标明电压、引脚定义、注意事项、禁止操作

### 9.7 DCDC模块PCB布局布线的核心方法 [来源：RYDZ智能车板]

**大电流功率回路的"最短最粗"原则**：
- 功率回路路径：输入电容→芯片VIN引脚→续流二极管→电感→输出电容→GND。这条路径上的走线必须最短且最宽。
- 实现方式：直接**铺铜代替走线**（不是画粗线，是用多边形铺铜工具）。实测铺铜宽度可达200-375mil（5-9.5mm）。

**反馈引脚（FB）的走线隔离**：
- FB引脚走线要远离电感L1，避免电感电磁场干扰采样信号
- 固定输出版本（FB直接接VOUT）：仅需保证走线短
- 可调版本（FB通过两个分压电阻设定电压）：两个分压电阻必须尽可能靠近FB引脚放置

**信号线与功率线的空间隔离** [来源：RYDZ智能车板]：
- 编码器反馈信号线、PWM控制线不要从大电流电机驱动线中间穿过
- 最好从芯片下方或板边绕行，让电机线绕到远离信号线的区域再汇合
- 原因：大电流线有电磁干扰，会导致控制信号采集波动

### 9.8 特定MCU平台注意事项

**STC89C52系列（51单片机）** [来源：Expert强化篇 P18-P20]：
- P0口上电复位后为"开漏输出"，无法输出高电平。若P0口作普通IO使用，必须外加10K上拉电阻（接5V）
- P1/P2/P3/P4上电复位后为准双向口，无需上拉
- 灌电流能力远大于拉电流能力，因此LED阴极接IO口、阳极接电源（电流流入IO口），IO口输出低电平时LED点亮

**MSPM0系列（TI Cortex-M0+）** [来源：RYDZ MSPM0系列]：
- PA2必须用0.1%精度100K下拉电阻到GND（不可用普通1%或5%精度电阻，实测芯片工作不正常）
- VCORE引脚：内部核心电压输出引脚，需单独接470nF电容到地（不得接其他电路），电容需靠近芯片，走线最短
- PA0/PA1可耐受5.5V，可通过10K/4.7K/47K电阻上拉到5V或3.3V
- LDO必须使用而非DC-DC：DC-DC有纹波会影响MCU稳定工作

**STM32G0系列** [来源：已有知识]：
- 仅支持低速无源晶振+高速有源晶振，用8MHz无源晶振会导致代码跑不通

### 9.9 单面贴片与全插件设计原则 [来源：RYDZ智能车板]

**单面贴片原则**：
- 设计时将所有元件放在同一面（顶层），避免双面贴片
- 原因：双面贴片用热风枪焊接时，吹一面会导致另一面的锡熔化、元件掉落。给加工厂做也会多收约500元工程费

**全插件设计（X后缀）**：
- 所有元件均为插件（电解电容、排针、按键、接线端子）
- 只需要一把电烙铁完成全部焊接，适合学生/电赛场景
- 混合设计（既有贴片又有插件）需要两道工序：先用加热台/热风枪焊贴片，冷却后再用电烙铁焊插件，增加工时和出错概率

### 9.10 常见错误与排错经验 [来源：MSPM0 + Expert强化篇]

| 问题 | 原因 | 解决 |
|------|------|------|
| 布线完成后发现某引脚未引出 | 原理图检查时不仔细 | 回原理图修改，更新到PCB，重布该区域 |
| 滤波电容离芯片太远 | 布局时未优先考虑电容位置 | 删除附近布线，移动电容靠近芯片，重新走线 |
| DRC报错-GND未连接 | 个别GND引脚被孤立 | 手动拉线或打过孔接到地铜皮 |
| 晶振下方有铺铜 | 铺铜时未设置禁止区域 | 晶振下方添加禁止铺铜区域（顶层+底层） |
| 丝印越界/模糊 | 丝印未经3D预览检查 | 用3D预览逐项检查，调整位置和字号 |
| 泪滴后DRC报错 | 添加泪滴后未重建铺铜 | 按规范流程：泪滴→重建铺铜→DRC |
| 新工程线距默认4mil | 未修改设计规则 | 养成设计前先改规则的习惯，统一用6mil |

### 10.3 DRC规则设置详解

**原理图DRC**：全部勾选。

**PCB DRC矩阵解读**：
- 行/列分别为导线、焊盘、过孔等元素类型
- 行列交点即为两者间距要求（如导线-导线=4mil，焊盘-焊盘=6mil）

**关键默认值**：
- 信号线宽：默认10mil(0.254mm)，最小5mil，最大100mil
- 差分对内线宽：信号线线宽，间距6mil，误差10mil（实际USB项目改为5mil）
- 过孔默认：外径24mil/内径12mil

**线距设置** [来源：RYDZ智能车板]：
- 推荐统一使用**6mil**而非默认4mil。原因是嘉立创4mil可白嫖，但淘宝等其他PCB厂商通常只支持6mil的白嫖规则
- 每次新建工程后设计规则会恢复为4mil，需养成**设计前先修改规则**的习惯

**铺铜连接方式**：
- 推荐"发散"（十字连接/热焊盘），线宽10mil，间距10mil，90度
- 选择"直连"则焊接需要大功率烙铁

**阻焊拓展**：顶层/底层均为2mil。

### 10.4 效率技巧补充

- 快速删除网络标签：选中芯片右键→删除网络标签→按住CTRL多选要保留的引脚→勾选"将引脚名称填入网络标签"→确定
- 网络标签对齐：选中后可拉长导线让布局更清晰
- 多次更新到PCB：画一部分引脚引出就更新一次，检查是否有遗漏，防止最后大幅修改
- 图纸尺寸：引脚数多时可将图纸改为A3尺寸
- `Q`：单位切换（mil/mm）
- 对齐快捷键建议全部在工具栏勾选显示

## 十一、元件封装绘制方法 [新增，来源：Expert强化篇 P28-P29]

当嘉立创EDA库中没有现成封装时，需自行绘制元件符号和封装。

### 11.1 元件符号绘制流程（以LM358DT为例）

| 步骤 | 操作 | 细节 |
|------|------|------|
| 1 | 查阅数据手册 | 立创商城搜索器件→打开数据手册→找到厂家提供的符号图 |
| 2 | 画外框 | 工具栏选择"矩形"绘制芯片体边框 |
| 3 | 放置引脚 | 引脚电气连接点（灰色十字箭头端）朝外，另一端接芯片 |
| 4 | 命名引脚 | 属性栏修改"引脚名称"（功能名如OUT1）和"引脚编号"（1-8沿逆时针） |
| 5 | 调整长度 | 引脚长度0.2→0.1使符号更紧凑 |
| 6 | 添加1号脚标记 | 在1号引脚旁放置小圆点 |

**引脚属性关键区分**：
- **引脚编号**（横杠上方数字）：对应封装焊盘编号
- **引脚名称**（横杠右侧文字）：芯片功能描述

### 11.2 封装尺寸参数提取

从数据手册 Package Information 章节提取关键尺寸：
- 焊盘宽度(B)：取手册最大值并适当加大（如B=0.48mm max→取0.6mm）
- 引脚长度(L1)：取典型值并适当加大（如L1=1.04mm典型→取1.9mm）
- 引脚间距(e)：严格按手册（如1.27mm）
- **两排焊盘间距计算公式**：E1 + 焊盘高度

### 11.3 三种焊盘阵列创建方法对比

| 方法 | 操作 | 适用场景 |
|------|------|----------|
| **手动坐标复制** | 复制焊盘后逐个输入X坐标(0, 1.27, 2.54, 3.81) | 少量引脚，精度要求高 |
| **智能尺寸** | 依次点击相邻焊盘中心，修改间距值 | 类似SolidWorks操作习惯者 |
| **线性阵列** | 放置→焊盘→条形多焊盘，设置数量/间距 | **最快**，自动编号 |

### 11.4 丝印绘制规范

- 顶层丝印层画矩形框表示芯片大致轮廓
- 正方向标识两种方式：(1)放置小圆点（空心/实心均可）；(2)在芯片中间画半圆
- 1号引脚标识：小实心圆（半径0.15，线宽0.3）

### 11.5 封装绑定与验证

- 库→个人→右键元件符号→绑定封装→选择个人库中的封装
- 验证：放置到原理图→更新到PCB→3D视图检查

## 十二、PCB设计完整流程总结 [新增，来源：Expert入门篇 P12 + 各项目实战]

### 12.1 标准四步管线
```
原理图设计 → PCB设计 → 生产加工 → 焊接组装
```

### 12.2 详细流程（10步）

1. 新建工程/创建板子（文件夹下新建原理图+PCB）
2. 原理图绘制：元件选型与电路设计→放置器件→原理图布线→**DRC检查**
3. 原理图转PCB + 导出BOM表
4. PCB设计：放置板框→**布局**（最关键步骤之一）→**布线**（最关键步骤之二）→DRC检查
5. 导出Gerber（生产文件）
6. 嘉立创下单打板

### 12.3 DRC的质量保证思维

- DRC（Design Rule Check）= 硬件开发的"编译检查"——类似于软件中编译通过才能烧录，DRC通过才能发板打样
- 检测内容：短路、引脚悬空、间距违规等电气连接错误
- 双重DRC：原理图DRC + PCB DRC
- 快捷键：Ctrl+W
- 设计前开启"实时DRC检测"功能，画板过程中实时报错

### 12.4 生产文件导出与下单流程 [来源：Expert强化篇 P24]

1. 导出Gerber文件：文件→导出→PCB制版文件（Gerber）
2. 下载"嘉立创下单助手"（小熊图标）
3. 优惠券中心领取免费打样券（每月2次，1~4层板）
4. PCB订单→计价下单→上传Gerber文件
5. 板子数量选5块，板材FR4，厚度0.8~1.6mm免费
6. 阻焊颜色选所需（黑色"比较有科技感"）
7. SMT和钢网选不需要（手动焊接）
8. 使用优惠券→0元提交→约4~5天到手
