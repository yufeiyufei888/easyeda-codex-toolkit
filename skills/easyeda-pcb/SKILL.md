# 嘉立创EDA PCB设计与审查

本技能覆盖嘉立创EDA专业版（V3）的完整PCB设计流程，分为**设计模式**和**审查模式**两条分支。

> **重要前置动作**：每次被触发时，先判断用户意图属于哪个模式（设计/审查/速查），然后进入对应分支。若用户意图模糊，主动询问：**"你是在画PCB需要指导，还是已经画完了需要我审查？"**

---

## 模式一：设计模式（用户正在画PCB）

适用场景：用户正在进行PCB布局、布线、扇出、铺铜等操作，需要逐步指导。

### Step 1：准备阶段

**目标**：原理图就绪，设计规则配置完毕，层叠方案确定。

**操作清单**：

1. **元件选型与数据手册阅读**（新增，推荐在画原理图前完成）
   - 从立创商城/半导小芯获取芯片数据手册
   - 按优先级阅读：引脚配置 -> 典型应用电路 -> 电气特性 -> 特性/应用
   - 芯片外围元件参数以数据手册推荐值为准（非经验猜测）
   - 完整选型方法论见 `references/component-selection-guide.md`
   - [来源: Expert电子实验室入门篇P6]

2. **原理图更新到PCB**
   - 快捷键 `Alt+I`，勾选"包含设计规则"以同步差分对、网络类、等长网络组
   - 被屏蔽的器件转换时自动移除，确认是否遗漏

3. **设置设计规则（DRC）**
   - 进入 `设计 > 设计规则`
   - **安全间距**：嘉立创两层板最小线宽/线距为4mil，建议设计值不小于**6mil**（理由：6mil可兼容淘宝等其他PCB厂商的白嫖规则，4mil仅嘉立创支持）
   - **导线宽度**：默认规则适用于信号线（如5~10mil），电源网络单独新建规则（详见 `references/design-rules.md`）
   - **铺铜间距**：默认10mil，根据电压等级调整
   - 规则可分层设置（顶层/底层独立），也可全层统一
   - 每次新建工程后设计规则会恢复为4mil，需养成**设计前先修改规则**的习惯
   - [来源: 荣洋电子RYDZ智能车系列]

4. **定义网络类（推荐）**
   - 使用 `网络类管理器` 将信号分组（如所有电源网络归入 "PWR_CLASS"）
   - 为网络类分配独立线宽规则，如电源类：最小10mil、默认20mil

5. **确认层叠方案**
   - 两层板：顶层信号/器件 + 底层信号/器件
   - 四层板：TOP信号 → GND平面 → VCC平面 → BOT信号（推荐方案见 `references/design-rules.md` 叠层章节）

6. **嘉立创EDA软件环境设置**（推荐首次使用配置）
   - 必须使用桌面客户端（在线编辑器卡顿且不稳定）
   - 推荐全在线模式（工程和库存服务器，不占本地空间）
   - 封装默认单位设为**毫米(mm)**（数据手册尺寸均为毫米）
   - 自动保存开启，10分钟间隔；自动备份开启
   - 快捷键方案选"立创EDA标准版"
   - [来源: Expert电子实验室强化篇USB拓展坞]

**完成标准**：
- [ ] 芯片数据手册已查阅，外围元件参数有据可查
- [ ] 原理图已更新到PCB，无遗漏器件
- [ ] 设计规则已按项目需求配置（间距≥6mil、线宽按电流、铺铜）
- [ ] 网络类已分组，电源网络规则已分配
- [ ] 板框尺寸确定，层数确定

### Step 2：布局阶段

**目标**：关键器件就位，模块分区清晰，结构/散热约束已确认。

**操作清单**：

1. **放置关键器件优先**
   - 先放置 MCU/主控（高密度引脚区，便于以此为锚点展开布局）
   - 再放置接口器件（TYPE-C、排针、SD卡座等，位置受结构约束）
   - 后放置电源模块（LDO/DCDC，靠近供电端）

2. **模块化分区布局**
   - 使用 `布局传递（Ctrl+Shift+X）`：在原理图框选某模块 → PCB中自动选中对应器件
   - 使用 `元件区域分布（Shift+P）`：选中多个器件，画区域，器件自动排布
   - 使用 `交叉选择（Shift+X）`：原理图选中 → PCB高亮定位
   - 按信号流向排列：电源输入 → 电源转换 → 主控 → 功能电路 → 输出接口

3. **对齐与分布**
   - 框选器件 → 上方"布局"选项栏 → 对齐/等距分布
   - 善用网格：布局阶段设2mm粗格，精调时改0.254mm细格

4. **约束区域（高密度区）**
   - MCU/BGA/LQFP 周围绘制 `约束区域`，为区域内指定更细的线宽和更小的间距
   - 此法避免全局使用过细规则导致普通区域浪费空间

5. **结构/散热确认**
   - 器件至板边有最小间距要求（软件黄色叉号提示DRC）
   - 发热器件（LDO、电机驱动芯片）远离热敏元件，预留散热空间
   - 挖槽区域靠近板框时即使无DRC报错也可能断裂，提前咨询板厂工艺

6. **布局进阶原则**（新增）
   - **竞赛级布局标准**（蓝桥杯EDA竞赛）：元件平行或垂直排列、分布均匀疏密一致、顶层优先
   - **三维高度意识**：PCB是二维画图但元件有高度，屏幕下方不能放高元件，电解电容/散热器/大电感需检查高度干涉
   - **根据使用特点布局**：接口/按键/排针放板子边缘，屏幕/主控放板子中央
   - **模块化布局**：同一功能电路放同一区域，方便布线和调试
   - **布局为布线让路**：布线中发现问题主动调换元件位置，不死守布局
   - **滤波电容就近放置**：先大后小（大电容远一点，小电容贴近引脚）；空间不够时电容可放底层
   - **单面贴片原则**：所有元件放同一面，避免双面贴片导致焊接困难（加工厂双面贴片多收约500元工程费）
   - [来源: Expert电子实验室强化篇51核心板、荣洋电子RYDZ MSPM0系列]

**完成标准**：
- [ ] 所有关键器件（MCU、接口、电源）位置已确定
- [ ] 模块分区清晰，信号流向合理
- [ ] 结构件（接口、按键、螺孔）位置与实际外壳匹配
- [ ] 大功率/发热器件已考虑散热
- [ ] 元件排列整齐，疏密一致（竞赛场景）
- [ ] 三维高度无冲突
- [ ] 建议：关键器件位置锁定（右键→锁定），防止布线时误移

### Step 3：布线阶段

**目标**：电源/地优先、关键信号优先、差分对等长到位、无明显绕线。

**布线优先级**：差分信号(最优先) → 晶振/时钟 → 关键信号(复位/模拟) → 普通数字信号 → 电源线 → GND铺铜

**操作清单**：

#### 3.1 电源与地线布线

- 电源线宽按电流选择（速查见 `references/design-rules.md` 线宽-电流表）
- 布线中按 `Tab` 临时覆盖线宽；右侧属性"起始布线宽度"选"**跟随规则**"使规则生效
- 地线优先使用铺铜（大面积地平面），而非细走线
- 多路布线时 `Tab` 统一修改线宽
- **大电流路径**（>2A）：用**多边形铺铜工具代替走线**，实测铺铜宽度可达200-375mil，远超过普通走线载流能力。各段网络属性必须正确，不能互相覆盖
- **电源线宽取焊盘宽度**：先查看目标焊盘宽度，线宽不超过焊盘宽度（否则DRC报错）
- **取电点在滤波电容之后**：必须从滤波电容之后取电，不从未滤波端取电
- [来源: Expert电子实验室强化篇USB拓展坞、荣洋电子RYDZ智能车系列]

#### 3.2 关键信号布线

- **晶振**：紧靠MCU，负载电容紧靠晶振，晶振下方禁止走线，远离板边
- **晶振高级屏蔽**（Via Fence技术）：①晶振电路外围打一圈GND过孔组成屏蔽环；②用20mil粗GND线将所有屏蔽过孔串联；③放置多层禁止铺铜区，防止铺铜铺到晶振电路
- **晶振差分对**：Alt+D定义差分对，走线先经过负载电容再进入晶振，长度差控制在10mil以内
- **模拟信号**（ADC输入、运放）：远离数字信号和开关电源，必要时包地隔离
- **时钟/高频信号**：走线尽量短直，避免过孔，控制阻抗
- **MSPM0特殊注意**：VCORE引脚仅接470nF电容到GND，走线最短；PA2下拉电阻必须±0.1%精度
- [来源: Expert电子实验室强化篇51核心板、荣洋电子RYDZ MSPM0系列]

#### 3.3 普通信号布线

- 嘉立创EDA快捷键：`Alt+W` 单路布线
- **多路布线**：选中多根同方向走线一次性拉出，快捷键为波浪线（可自定义），大幅提高效率
- 按 `Tab` 修改布线参数（线宽、过孔尺寸等）
- 优先走顶层，必要时切换底层，过孔数量尽量少
- **焊盘出线原则**：从焊盘**短边**引出，不从长边出（长边出会形成两个直角）
- **走线角度**：禁止走90度直角（直角等效贴片天线，产生EMI辐射），只走135度钝角或圆弧
- **元件内部不走线**：原则上不穿过元件内部走线
- [来源: Expert电子实验室强化篇51核心板、荣洋电子RYDZ智能车系列]

#### 3.4 差分对布线

- **前提**：在 `差分对管理器` 中创建差分对（如 USB_DP/USB_DN），设置线宽、对间间距、最大误差范围
- 差分对信号命名需遵循 `_P/_N` 或 `_DP/_DN` 规则，系统可自动识别
- 布线快捷键 **`Alt+D`** 自动按差分对规则引出并保持间距
- 对内长度不一致时：用 `等长调节（Shift+A）` 或反方向增加拐角消除误差
- 多组差分对之间也需要等长
- **差分线7条设计规则**（具体数值）：①尽量短；②优先绘制；③不超过2对过孔；④平行紧密走线；⑤**线长差<5mil**；⑥与其他信号间距>20mil；⑦USB差分阻抗90Ω。详见 `references/high-speed-guide.md`
- [来源: Expert电子实验室强化篇USB拓展坞]

#### 3.5 等长布线

- 创建 `等长网络组`（如 PA0~PA7 加入同一组）
- 在 `网络规则 > 网络长度公差` 中指定**基准网络**，设置公差范围
- 执行等长调节：快捷键 **`Shift+A`**，选中导线向空闲区域拖动 → 自动增加蛇形走线
- `Tab` 设置蛇形走线参数：长度、拐角样式、走线约束
- 若有分支（芯片→排针→按键），使用 `焊盘对组` 仅关注关心段长度

#### 3.6 扇出（LQFP/BGA）

- **LQFP**：扇出类型选"向外/向内/向外向内"
- **BGA**：盘中孔扇出，可勾选"仅扇出外面两行焊盘"
- 扇出参数：线宽、过孔尺寸、过孔到焊盘间距、最小通道间距
- 若触发DRC，可临时勾选"忽略DRC报错"强制扇出
- 无网络焊盘需勾选"无网络焊盘扇出"

**完成标准**：
- [ ] 差分信号已优先布线，线长差<5mil
- [ ] 晶振已做Via Fence屏蔽 + 禁止铺铜区
- [ ] 电源线宽满足载流要求，大电流已用铺铜代替走线
- [ ] 所有网络已连通（无飞线）
- [ ] 差分对已按规则布线，对间/对内长度符合公差
- [ ] 等长组内各网络长度在公差范围内
- [ ] 模拟等关键信号处理正确
- [ ] 无90度直角走线
- [ ] 过孔数量合理，无不必要绕线

### Step 4：后处理阶段

**目标**：铺铜完整、泪滴已加、丝印清晰、DRC通过。

**操作清单**：

1. **铺铜**
   - 顶层和底层分别铺铜（通常接GND网络）
   - 铺铜间距可在规则中调整（默认10mil）
   - 选中铺铜区域 → 右侧属性可一键"放置缝合孔"（手动设置行距/列距）
   - **铺铜连接方式**：推荐"发散"（十字连接/热焊盘），方便手工焊接。大电流场景选"直连"但需大功率烙铁
   - **缝合孔自动放置**：铺铜后使用"放置/移除缝合孔"功能（外径24mil/内径12mil，行距/列距30~80mil），自动均匀打GND过孔。**不要怕过孔多**，机器打孔极快
   - [来源: 荣洋电子RYDZ MSPM0系列、Expert电子实验室强化篇51核心板]

2. **泪滴**
   - 作用：加强导线与焊盘连接、平滑信号传输
   - 支持圆弧泪滴，可设置宽度/高度
   - 应用范围：导线→多层焊盘、导线→单层焊盘、导线→导线交叉处
   - **自动添加**：设置 → PCB → 通用 → 布线 → 勾选"自动添加泪滴"
   - **注意顺序**：铺铜完成 → 添加泪滴 → **重建铺铜** → DRC检查（类滴后不重建铺铜会导致DRC报错）
   - [来源: Expert电子实验室强化篇51核心板、荣洋电子RYDZ MSPM0系列]

3. **缝合孔/回流孔**
   - 菜单放置 > 缝合孔（支持矩形/多边形/线条区域）
   - 参数：GND网络、外径、内径、行距、列距
   - 缝合孔需遵循过孔设计规则，超规会DRC报错
   - 更高效：选中铺铜 → 右侧属性 → 放置缝合孔 → 一键铺满
   - 未铺上铜的孤岛区域（蓝色显示）需手动补打过孔

4. **丝印调整**
   - 器件位号避免放在焊盘/过孔上
   - 极性标识（二极管正负、电容正极、IC一脚标记）清晰可见
   - 可添加板名、版本号、日期等辅助丝印
   - **丝印对齐技巧**：先确定首尾两个丝印位置 → 框选整列 → 右对齐+垂直等间距 → 自动排列
   - **开关方向标识**：在"开"方向放小圆点（半径10mil圆形），标明拨杆方向
   - **排针引脚标注**：在排针下方/上方放置引脚编号/功能文本，高度45~60mil，线宽5mil
   - **背面丝印**：复制顶层丝印后切换到底层丝印层，包含板名、引脚定义表（如"LED1=PB0"）、正负极标识、注意事项。丝印=给队友的"硬件文档"
   - **图片导入丝印层**：放置 → 图片，导入logo，可调容差/简化参数控制线稿精细度
   - [来源: Expert电子实验室强化篇51核心板、荣洋电子RYDZ MSPM0/智能车系列]

5. **DRC检查**
   - 运行 `设计 > 检查DRC`（快捷键 Ctrl+W），消除所有错误
   - **实时DRC**：设计菜单中勾选"实时DRC检测"，画板过程中实时报错
   - 黄色警告逐项确认（有些可接受，有些需处理）
   - 常见DRC：间距不足、线宽不匹配、未连接网络、丝印重叠
   - DRC错误解析：关注错误类型、涉及对象、违反规则、解释信息

**完成标准**：
- [ ] 顶层/底层铺铜完整，死铜已移除
- [ ] 泪滴已添加，关键焊盘连接可靠
- [ ] 缝合孔数量合理（高速/多层板更需关注）
- [ ] 丝印清晰、无重叠、极性标注明确，背面丝印含引脚定义
- [ ] DRC无错误，警告已审查确认

### Step 5：生产输出阶段

**目标**：Gerber/BOM/装配图齐全，下单参数正确。

**操作清单**：

1. **生成Gerber文件**
   - `制造 > Gerber输出` / 文件 → 导出 → PCB制版文件（Gerber）
   - 选择需要的图层
   - 确认钻孔文件包含在内

2. **导出BOM**
   - `制造 > BOM导出`，确认器件型号、封装、位号完整

3. **导出装配图**
   - `制造 > 装配图输出`，用于SMT贴片

4. **下单检查清单**
   - 板厚、铜箔厚度（默认1oz，大电流可选2oz）
   - 层数、颜色（阻焊/丝印）
   - 表面处理（有铅/无铅喷锡、沉金等）
   - 最小线宽/线距是否在板厂工艺能力内

5. **嘉立创下单流程**（新增）
   - 下载"嘉立创下单助手"（小熊图标）
   - 优惠券中心领取免费打样券（每月2次，1~4层板，10x10cm以内免费）
   - PCB订单 → 计价下单 → 上传Gerber文件

## 模式二：审查模式（用户要求审查已完工PCB）

适用场景：用户已完成PCB设计，需要第三方视角的审查意见。

> **核心约束**：审查模式**只列出问题清单和建议，不直接修改用户的工程文件**。每项问题附带具体位置、风险等级和建议修复方案。

### Step 1：布局审查

逐项检查以下内容：

- [ ] 结构件（接口、按键、螺孔）位置是否与外壳/结构匹配
- [ ] 是否有器件离板边过近（DRC黄色叉号提示）
- [ ] 高密度区域（BGA/LQFP）是否留有足够的扇出/布线空间
- [ ] 发热器件是否与热敏元件（晶振、运放、温度传感器）保持距离
- [ ] 模块分区是否清晰，电源靠近输入端、MCU居中、接口靠边
- [ ] 贴片器件的方向一致性（极性器件方向尽量统一，方便焊接检查）
- [ ] 是否有器件互相遮挡（高度干涉）或影响插拔
- [ ] 滤波电容是否紧靠被滤波引脚（先大后小）
- [ ] 晶振是否紧靠MCU、负载电容是否紧靠晶振
- [ ] 是否所有贴片元件在同一面（单面贴片原则，双面贴片多收500元工程费）
- [ ] [来源: Expert电子实验室强化篇、荣洋电子RYDZ]

### Step 2：布线审查

逐项检查以下内容：

- [ ] 电源走线宽度是否满足载流要求（对照 `references/design-rules.md` 线宽-电流表）
- [ ] 晶振是否紧靠MCU、负载电容是否紧靠晶振、下方是否无走线、是否有Via Fence屏蔽
- [ ] 关键信号（时钟、复位、模拟输入）是否远离干扰源（开关电源、PWM走线）
- [ ] 差分对走线是否等长、等间距，对内长度误差是否<5mil
- [ ] 等长组内各网络长度差是否在公差内
- [ ] 是否存在不必要的过长走线或过多过孔
- [ ] **禁止直角走线**（90度拐弯=贴片天线=EMI辐射源）
- [ ] 是否有浮空铜皮或死铜
- [ ] 焊盘是否从短边出线
- [ ] 大电流路径是否用铺铜代替细走线
- [ ] [来源: Expert电子实验室强化篇、荣洋电子RYDZ智能车系列]

### Step 3：电源/地审查

逐项检查以下内容：

- [ ] 电源输入路径是否经过必要的保护器件（防反接二极管、保险丝、TVS等）
- [ ] LDO输入/输出电容是否靠近引脚放置
- [ ] DCDC电路Layout：输入电容是否靠近芯片Vin/GND引脚（关键！寄生电感可能引起电压尖峰击穿MOSFET）
- [ ] DCDC SW节点面积是否尽量小（减少EMI辐射）
- [ ] 功率回路面积是否尽量小（Vin→上管→电感→输出电容→地→下管→Vin）
- [ ] 反馈信号（FB）是否远离SW节点和电感等噪声源
- [ ] 地平面是否完整，是否存在割裂（尤其高速/模拟区域）
- [ ] 模拟地和数字地是否做了合理隔离（磁珠单点接地）
- [ ] 电池电量检测分压电阻是否靠近ADC引脚
- [ ] DCDC电感是否为一体成型（屏蔽式）电感，非开放式
- [ ] DCDC续流二极管是否为肖特基二极管且额定电流留50%余量
- [ ] [来源: 荣洋电子RYDZ智能车系列]

### Step 4：DFM（制造可行性）审查

逐项检查以下内容：

- [ ] 最小线宽/线距是否在板厂工艺能力内（建议≥6mil以兼容多家厂商）
- [ ] 最小过孔尺寸是否在板厂能力内
- [ ] 器件焊盘是否完整，无残缺或被丝印覆盖
- [ ] BGA焊盘是否有过孔打在焊盘上（盘中孔需要特殊工艺）
- [ ] 板边器件是否有足够的工艺边/夹持边
- [ ] 拼板/V-Cut设计是否合理（如适用）
- [ ] 是否有过小的挖槽区域（板厂可能放大或无法生产）
- [ ] 丝印是否清晰可辨，无重叠或放在焊盘上

### Step 5：输出问题清单

汇总格式（每个问题一行）：

```
[风险等级] [类别] 位置/网络 - 问题描述 → 建议修复方案

风险等级：
  严重 - 会导致电路不工作或损坏
  高   - 很可能影响性能或可靠性
  中   - 不符合设计规范，建议修正
  低   - 优化建议，可选择性处理
  信息 - 提示/注意事项
```

类别：布局 / 布线 / 电源 / 地 / DFM / EMC / 散热

## 通用建议与经验法则

### PCB布局铁律
1. **晶振靠近MCU，负载电容靠近晶振，晶振下方不走线，远离板边，加Via Fence屏蔽**
2. **滤波电容紧靠被滤波引脚**（输入/输出电容各靠近LDO放一个，先大电容再小电容）
3. **按信号流向布局**（电源左进→MCU居中→接口右出）
4. **先铺铜再调丝印**——铺铜后可能遮挡丝印
5. **大电流路径优先确认**，线宽不够是整个板子的瓶颈

### PCB布线铁律（新增）
6. **走线禁止直角**：直角=贴片天线=EMI辐射源，只走135度钝角或圆弧
7. **焊盘从短边出线**：不从长边出，避免形成两个直角
8. **电源取电在滤波电容之后**：不从未滤波端取电
9. **GND过孔不怕多**：机器打孔极快，空白区域多放GND缝合孔
10. **大电流不用粗线用铺铜**：>2A时用多边形铺铜工具代替走线
11. **差分线先布、晶振线先布**：重要信号优先级最高
12. **类滴后必须重建铺铜**：铺铜→泪滴→重建铺铜→DRC，顺序不可乱
[来源: Expert电子实验室强化篇、荣洋电子RYDZ智能车系列]

### DRC常见问题处理
| 错误类型 | 原因 | 解决 |
|---------|------|------|
| 间距不足 | 导线/焊盘/铺铜距离过近 | 增大间距或调整规则 |
| 线宽不匹配 | 布线宽度不符合规则设定 | 修改线宽或调整规则 |
| 网络未连接 | 飞线存在，布线未完成 | 补齐走线或使用铺铜连通 |
| 丝印重叠 | 位号印刷重叠 | 调整丝印位置或隐藏不必要丝印 |
| 过孔尺寸超规 | 过孔内径/外径小于规则 | 增大过孔或修改规则 |
| 未连接引脚 | 原理图有悬空引脚 | 确认是否需要连接或加非连接标识 |
| 直角走线 | 90度拐角 | 改为135度钝角或圆弧走线 |

### 设计规则命名建议
- 信号线规则：`SIG`（5~10mil）
- 电源线规则：`PWR`（15~40mil，按电流）
- 差分对规则：`DIFF90`（90Ω阻抗差分对）、`DIFF100`（100Ω）
- 铺铜规则：`COPPER`（10~15mil间距）

### 从原理图到PCB的规则传递
- `Alt+I` 更新时勾选"包含设计规则"
