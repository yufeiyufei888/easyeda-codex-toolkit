## 一、PCB物理结构

### 1.1 基本结构（类比：三明治）

- **基板材料**：PP半固化片 + 芯板（玻璃纤维+固态树脂）
- **覆铜板结构**：铜箔层 / 固态树脂 / 玻璃纤维
- **双层板剖视图**：顶层铜箔 -> 芯板 -> PP层 -> 底层铜箔

### 1.2 多层板结构

| 层数 | 典型层叠（从上到下） |
|------|---------------------|
| 双层板 | 顶层信号 + 底层信号 |
| 四层板 | 顶层信号 / 电源层 / 地层 / 底层信号 |
| 六层板 | 信号 / 地 / 信号 / 电源 / 地 / 信号 |

叠层设计：哪一层做信号、哪层做电源/地，由设计者自行规划。

### 1.3 过孔类型

| 类型 | 特征 | 工艺成本 |
|------|------|----------|
| 通孔(Through Hole) | 从顶层贯穿到底层，所有层可见 | 最低 |
| 盲孔(Blind Via) | 从顶层或底层到中间某层停止，表面可见 | 较高 |
| 埋孔(Buried Via) | 起点终点都在内层，PCB表面不可见 | 最高 |

> **建议**：常规设计只用通孔，盲埋孔工艺贵且嘉立创免费打样不支持。

## 二、PCB板上物理元素

| 元素 | 功能 | 说明 |
|------|------|------|
| **导线** | 连接不同元件引脚 | 细铜箔，载流能力取决于宽度 |
| **铺铜(Copper Pour)** | 大面积的GND或电源铜皮 | 比导线有更好的载流和散热能力 |
| **十字连接（热焊盘）** | 焊盘与铺铜的连接方式 | 防止焊接时铜皮散热太快导致虚焊 |
| **填充(Fill/直连)** | 焊盘与铺铜的直接连接 | 用于过大电流场景，但焊接需大功率烙铁 |
| **焊盘** | 元件焊接点 | 表贴式（无孔）vs 通孔式（有孔） |
| **丝印** | PCB表面的白色文字/logo | 元件位号、极性标识、版本号等 |
| **阻焊** | 覆盖在铜层上的油墨 | 保护铜层、防止焊接短路；开窗区域露出焊盘 |

## 四、电路分析基础

### 4.1 集总参数电路

- **核心概念**：电磁现象只在元件内部发生，元件之间互不影响
- **适用条件**：实际电路尺寸 << 电磁波波长（频率越低越适用）
- 本课程范围的所有电路可用集总参数模型等效，不必考虑元件间相互位置影响

**电阻的等效模型随频率演进**：
- 理想/低频：纯电阻
- 中频：电阻+电感串联（电感效应显现）
- 高频：电阻+电感串联后与电容并联（电容效应显现）

### 4.2 电路基本名词

| 名词 | 定义 |
|------|------|
| 支路(Branch) | 通过同一电流的通路，由一个或几个串联元件构成 |
| 回路(Loop) | 闭合路径 |
| 独立回路 | 至少包含一个未曾用过的新支路的回路 |
| 网孔(Mesh) | 不可再分的最简回路（内部不含任何支路），网孔数=独立回路数 |

### 4.3 基尔霍夫定律

| | KCL（电流定律） | KVL（电压定律） |
|------|------|------|
| 对象 | 节点(或闭合面) | 回路 |
| 表述 | 流入=流出（代数和=0） | 电压降=电压升（代数和=0） |
| 物理本质 | 电荷守恒 | 能量守恒 |
| 推广应用 | 包围多节点的任意闭合面 | 任意闭合回路 |
| 无关项 | 支路上元件性质 | 支路上元件性质 |

**KVL列方程三步法**：
1. 标定各元件电压参考方向
2. 选定回路绕行方向（顺时针/逆时针）
3. 确定符号规则，沿回路走一圈代数和=0

### 4.4 原理图四要素

1. 元件符号
2. 连接线（实际PCB中=各种形状的铜箔）
3. 节点（红色小圆点，多条导线连接处；无红点=交叉但无连接）
4. 注释

**网络标签(Net Label)**：相同网络标签=电气连接。两大作用：(1)简化连线避免"盘丝洞"；(2)用引脚功能命名便于理解。

## 五、PCB设计完整流程

### 5.1 整体四步管线

```
原理图设计 -> PCB设计 -> 生产加工 -> 焊接组装
```

### 5.2 详细流程（10步）

1. 新建工程/创建板子（文件夹下新建原理图+PCB）
2. 原理图绘制：元件选型与电路设计 -> 放置器件 -> 原理图布线 -> DRC检查
3. 原理图转PCB + 导出BOM表
4. PCB设计：放置板框 -> 布局 -> 布线 -> DRC检查
5. 导出Gerber（生产文件）
6. 嘉立创下单打板

### 5.3 DRC（Design Rule Check）的核心定位

- 全称：设计规则检查
- 目的：确保设计满足特定制造工艺要求，属于质量保证措施
- 检测内容：短路、引脚悬空等电气连接错误
- 双重DRC：原理图DRC + PCB DRC
- **类比**：DRC = 硬件开发的"编译检查"，类似于软件中编译通过才能烧录

## 六、元件符号与封装

### 6.1 符号-封装对应关系

- **元件符号**：原理图中使用的逻辑符号
- **封装(Footprint)**：PCB中实际焊接的物理尺寸
- 两者通过"绑定"关联

### 6.2 封装绘制流程

1. 从数据手册 Package Information 章节提取尺寸
2. 关键尺寸：焊盘宽度(B)、引脚长度(L1)、引脚间距(e)、器件总长(E1)
3. **加大原则**：实际焊盘尺寸在数据手册基础上适当加大（如B=0.48取0.6，L1=1.04取1.9）
4. 两排焊盘间距 = E1 + 焊盘高度

### 6.3 三种焊盘阵列创建方法

| 方法 | 操作 | 适用场景 |
|------|------|----------|
| 手动坐标复制 | 复制焊盘后逐个输入坐标 | 少量引脚，精度要求高 |
| 智能尺寸 | 依次点击相邻焊盘中心，修改间距 | 类似SolidWorks操作习惯者 |
| **线性阵列** | 放置->焊盘->条形多焊盘，设置数量和间距 | **最快**，自动编号 |

### 6.4 丝印绘制规范

- 顶层丝印层画矩形框表示芯片轮廓
- 1号引脚标识：小实心圆（半径0.15，线宽0.3）
- 正方向标识：小圆点或半圆
