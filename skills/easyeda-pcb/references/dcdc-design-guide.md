## 一、DCDC拓扑速查

### 1.1 Buck（降压）拓扑

```
VIN -> 输入电容 -> 开关管(内置) -> 电感 -> 输出电容 -> VOUT
                    |
                 续流二极管 -> GND
```

- 代表型号：LM2596、XL1509、TPS5450
- 适用：VIN > VOUT

### 1.2 Boost（升压）拓扑

```
VIN -> 电感 -> 开关管(内置) -> 输出电容 -> VOUT
           |
        续流二极管 -|
```

- 适用：VIN < VOUT

## 二、Buck电路PCB布局核心方法

### 2.1 大电流功率回路的"最短最粗"原则

**功率回路路径**：输入电容 -> 芯片VIN引脚 -> 续流二极管 -> 电感 -> 输出电容 -> GND

这条路径上的走线必须**最短且最宽**。实现方式：**直接铺铜代替走线**（用多边形铺铜工具，不是画粗线）。

实测铺铜宽度可达200-375mil（5-9.5mm），远超过普通走线的载流能力。

> **铺铜注意事项**：各段网络属性必须正确（VIN段=输入网络，VCC段=输出网络，GND段=GND网络），各段不能互相覆盖否则造成短路。

### 2.2 输入电容放置（最关键！）

- 输入电容必须**紧靠芯片Vin和GND引脚**（<2mm）
- 原因：走线寄生电感会在SW开关瞬间引起输入电压尖峰，可能击穿内部MOSFET
- 先经过大电容（如680uF电解）再经过小电容（100nF陶瓷），小电容离芯片最近

### 2.3 SW节点面积最小化

- SW（开关节点）是DCDC电路中**最大的EMI辐射源**
- SW节点铜皮面积尽量小，刚好连接电感、二极管和芯片SW引脚即可
- 不要在SW节点上大面积铺铜

### 2.4 反馈引脚（FB）的走线隔离

- FB走线要**远离电感L1和SW节点**，避免电感电磁场干扰采样信号
- **固定输出电压版**：FB直接接VOUT，仅需保证走线短
- **可调输出电压版(ADJ)**：FB通过R1/R2分压电阻设定VOUT，**两个分压电阻必须尽可能靠近FB引脚放置**

### 2.5 电感选型与布局

- 必须使用**一体成型电感**（屏蔽式），禁止使用开放式电感
- 原因：开放式电感有磁通量泄漏，产生电磁干扰
- 一体成型电感下方不需要设置禁止铺铜区域
- 如果用开放式电感：电感正下方在顶层和底层都设禁止铺铜区域

### 2.6 地平面与过孔策略

- 底层做**完整地平面**
- 顶层GND孤岛通过打过孔连接到底层地平面
- 芯片散热焊盘（EP/GND，如LM2596的6号引脚）下方**多打过孔**到地平面，增强散热
- 养成在空白区域打GND缝合孔的习惯——增加电流路径、增强载流能力、改善EMI
- 使用"放置缝合孔"功能：铺铜区域右键 -> 放置缝合孔，设置行距/列距（推荐30mil）

## 三、可复用的DCDC设计模板（固定输出版）

```
VIN -> 保险丝 -> 开关 -> [大电容 // 小电容] -> DCDC VIN
                                              -> DCDC GND -> GND平面
                                              -> DCDC OUTPUT -> 续流二极管(阴极) -> 电感 -> [输出电容组] -> VCC
                                                                续流二极管(阳极) -> GND
                                              -> DCDC FB -> VCC(短接，固定输出版)
                                              -> DCDC ON/OFF -> GND(使能)
```

该模板仅更换芯片即可输出3.3V/5V/12V。

## 四、DCDC PCB检查清单

进行DRC前逐项自查：

- [ ] 输入电容紧靠芯片Vin-GND引脚（<2mm）
- [ ] SW节点铜皮面积最小化
- [ ] FB走线远离电感和SW节点
- [ ] 功率回路（Vin->上管->电感->输出电容->地->下管->Vin）面积最小
- [ ] 续流二极管靠近SW引脚和地
- [ ] 电感下方无不必要的铺铜（或仅GND铜皮且留足够间距）
- [ ] 输出电容尽量靠近电感和负载
- [ ] 底层地平面完整，未被信号线割裂
- [ ] 芯片散热焊盘下方有足够GND过孔

## 五、常见DCDC问题排查

| 问题 | 可能原因 | 解决 |
|------|----------|------|
| 输出电压不稳定 | FB走线受干扰 | FB远离电感和SW节点 |
| 芯片发热严重 | 输入电容太远导致电压尖峰 | 输入电容紧靠Vin-GND |
| EMI超标 | SW节点面积太大 / 开放式电感 | 缩小SW铜皮 / 换一体成型电感 |
| 带载能力不足 | 电感饱和电流不够 | 换大一档额定电流的电感 |
| 芯片烧毁 | 输入电容位置远导致MOSFET击穿 | 重新布局，电容紧贴芯片 |
