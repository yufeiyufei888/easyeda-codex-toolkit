# PCB审查Checklist

> 使用方式：逐项检查，打勾通过。未通过项记录到问题清单，标注风险等级。

---

## A. 布局审查（Placement）

### A1. 结构/机械
- [ ] 板框尺寸与外壳/结构图纸一致
- [ ] 固定孔位置、孔径与外壳匹配
- [ ] 接口器件（USB、RJ45、SD卡座、排针等）突出板边距离正确
- [ ] 按键、开关、电位器位置与面板开孔对齐
- [ ] 器件高度无干涉（尤其电解电容、散热器、大电感）
- [ ] 板边器件预留夹持边（5mm以上，无器件）
- [ ] 拼板Mark点/工艺边考虑（量产时）

### A2. 功能分区
- [ ] 电源电路靠近输入接口
- [ ] MCU/主控居中或靠近被控电路
- [ ] 高速/数字区与模拟区分离
- [ ] 大功率区与信号区分离
- [ ] 天线区域净空（如有RF，需4mm以上无铜区域）

### A3. 散热
- [ ] LDO/DCDC/电机驱动等发热器件远离热敏元件
- [ ] 大功率器件下方铺铜散热
- [ ] 热量不会聚集在封闭区域
- [ ] 电解电容远离热源（寿命与温度强相关）

### A4. 可制造性
- [ ] 贴片器件方向尽量一致（便于焊接检查）
- [ ] 极性器件方向统一（有极性电容、二极管、IC一脚）
- [ ] 插件器件引脚间有足够间距（便于手工焊接）
- [ ] 测试点/调试接口容易接触到

---

## B. 布线审查（Routing）

### B1. 关键信号
- [ ] 晶振紧靠MCU、负载电容紧靠晶振、下方无走线、周围禁止铺铜
- [ ] 复位信号远离干扰源、上拉电阻靠近MCU
- [ ] ADC模拟输入远离数字信号和开关电源
- [ ] 时钟/高频信号走线短直、尽量不过孔
- [ ] 天线馈线50Ω阻抗控制（如有RF）

### B2. 差分对
- [ ] 差分对创建正确（正/负网络在差分对管理器中成对）
- [ ] 差分对走线等长（对内误差在规格内，通常<5~10mil）
- [ ] 差分对走线等间距（全程保持恒定间距）
- [ ] 差分对过孔成对、对称放置
- [ ] 多组差分对之间等长（如需要）
- [ ] 差分对参考平面连续（下方无分割槽）

### B3. 等长组
- [ ] 等长网络组创建正确（如数据总线D0~D15）
- [ ] 基准网络指定正确
- [ ] 各组内网络长度差在公差内
- [ ] 蛇形走线参数合理（线距≥3倍线宽，减少串扰）

### B4. 一般信号
- [ ] 无浮空走线（悬空未连接的短线段）
- [ ] 无天线效应走线（长悬空短截线）
- [ ] 过孔数量合理（一个网络不宜>10个过孔）
- [ ] 无直角/锐角走线（高速信号禁止，低速信号不推荐）
- [ ] 无环路走线（形成环形天线）

---

## C. 电源审查（Power）

### C1. 电源走线
- [ ] 电源输入线宽满足最大电流要求（查线宽-电流表）
- [ ] 主电源干线从输入到各分支路径清晰
- [ ] 大电流路径用铺铜而非细走线
- [ ] 多过孔并联用于层间切换的大电流路径

### C2. 电源拓扑
- [ ] LDO：输入/输出电容紧靠引脚、压差在规格内
- [ ] DCDC：输入电容紧靠Vin-GND引脚（关键！距离<2mm）
- [ ] DCDC：SW节点面积尽量小（减少EMI）
- [ ] DCDC：反馈信号FB远离SW/电感等噪声源
- [ ] DCDC：功率回路面积最小化
- [ ] 升压/降压拓扑正确（见DCDC知识）

### C3. 去耦电容
- [ ] 每个IC电源引脚有去耦电容（0.1μF，尽量近）
- [ ] 大IC（MCU/FPGA）每个电源引脚组有对应去耦电容
- [ ] 去耦电容容值合理（高频用0.1μF+0.01μF，低频用10μF+）
- [ ] 电容靠近被滤波引脚，走线先经过电容再到IC引脚

---

## D. 地设计审查（Ground）

### D1. 地平面
- [ ] 铺铜完整，无大面积割裂
- [ ] 信号跨越分割区域有回流路径（加缝合孔/桥接电容）
- [ ] 高速信号下方参考平面连续
- [ ] 无孤岛铜皮（死铜），或已通过过孔连接

### D2. 接地策略
- [ ] 单点接地或多点接地策略明确
- [ ] AGND与DGND有磁珠/0Ω电阻隔离（如需要）
- [ ] 功率地与信号地分离后单点汇合（大电流场景）
- [ ] 外壳地与电路地连接方式正确（螺丝孔/弹片）

### D3. 缝合孔/回流孔
- [ ] 高速/高频板有足够缝合孔（减少地弹）
- [ ] 大面积铺铜边缘有缝合孔
- [ ] 信号换层处（过孔）附近有回流过孔

---

## E. EMC审查

### E1. 辐射
- [ ] 高速信号远离板边（20H规则：电源层比地层内缩20倍介质厚度）
- [ ] 开关电源SW节点面积最小化
- [ ] 高频信号走线尽量短
- [ ] 关键信号包地处理（两侧放GND走线+过孔）

### E2. 防护
- [ ] 外部接口有ESD防护（TVS二极管靠近接口）
- [ ] 电源输入有防反接/过压/过流保护
- [ ] 通信接口有必要的防护（USB有TVS/共模电感）
- [ ] 板边有地环/屏蔽地（高速/EMC敏感板）

---

## F. DFM（制造可行性）审查

### F1. 线宽线距
- [ ] 最小线宽 ≥ 板厂能力（嘉立创4mil，建议6mil+）
- [ ] 最小线距 ≥ 板厂能力
- [ ] BGA扇出区域线宽线距未超工艺极限

### F2. 过孔
- [ ] 最小孔径 ≥ 板厂能力（嘉立创0.2mm）
- [ ] 最小外径 ≥ 板厂能力（嘉立创0.45mm）
- [ ] 盘中孔（BGA内部）确认板厂支持（需塞孔+电镀填平）
- [ ] 过孔未打在SMT焊盘上（除BGA必须盘中孔外）

### F3. 丝印
- [ ] 丝印未覆盖焊盘（会导致焊接不良）
- [ ] 丝印线宽 ≥ 6mil
- [ ] 丝印字符高度 ≥ 32mil
- [ ] 位号与器件一一对应，无遗漏
- [ ] 极性标识清晰
- [ ] IC的1脚标记清楚

### F4. 阻焊
- [ ] 阻焊开窗正确（焊盘、测试点、金手指等）
- [ ] IC细间距引脚间有阻焊坝（避免连锡）
- [ ] 无意外阻焊开窗（短路风险）

### F5. 外形
- [ ] 拼板连接方式明确（V-Cut / 邮票孔 / 连接桥）
- [ ] 板边光滑无毛刺设计
- [ ] 异形板挖槽/铣槽线宽≥板厂能力（通常1.6~2.0mm）

---

## G. BOM/封装一致性审查

- [ ] 原理图封装与PCB封装一致（引脚数、焊盘尺寸、间距）
- [ ] 极性器件（二极管、钽电容、铝电解、LED）方向已标注
- [ ] QFN/QFP引脚1标识与封装一致
- [ ] 器件焊盘尺寸与实际元件匹配（尤其手工焊接需加长焊盘）
- [ ] BOM中所有器件有对应封装
- [ ] 可选焊（DNP/NC）器件在PCB中有焊盘

---

## H. DCDC电源专项审查 [来源: 荣洋电子RYDZ智能车系列]

- [ ] 输入电容紧靠芯片Vin-GND引脚（<2mm为佳）
- [ ] SW节点铜皮面积最小化（减少EMI）
- [ ] FB反馈走线远离电感和SW噪声源
- [ ] 功率回路面积最小化
- [ ] 续流二极管靠近SW引脚和地
- [ ] 电感使用一体成型（屏蔽式）电感，非开放式
- [ ] 芯片散热焊盘下方有足够GND过孔
- [ ] 输出电容尽量靠近电感和负载端

---

## H2. 电机驱动专项审查 [来源: 荣洋电子RYDZ智能车系列]

- [ ] 驱动线宽满足持续电流要求（TB6612驱动线≥20mil）
- [ ] 信号线（编码器反馈、PWM控制）远离大电流功率线
- [ ] VM电源输入线足够宽（≥30mil）或铺铜处理
- [ ] 多路驱动时各通道布局对称、网络标识清晰

---

## I. 特殊芯片专项审查 [来源: Expert电子实验室+荣洋电子RYDZ]

### I1. MSPM0系列
- [ ] PA2下拉电阻精度为±0.1%（100K），不得使用普通1%精度电阻
- [ ] VCORE引脚仅接470nF电容到GND，无其他连接
- [ ] PA0/PA1上拉电压在5.5V安全范围内

### I2. STC89C52系列
- [ ] P0口作为普通IO使用时已外加10K上拉电阻
- [ ] LED采用灌电流接法（阴极接IO口，阳极接电源）

---

## J. 布线规范专项审查 [来源: Expert电子实验室+荣洋电子RYDZ]

- [ ] 无直角走线（90度拐角等效于贴片天线，产生EMI辐射）
- [ ] 焊盘从短边出线（不从长边出，避免形成两个直角）
- [ ] 晶振电路：负载电容先于晶振、via fence屏蔽环+禁止铺铜区双重处理
- [ ] 电源取电点在滤波电容之后（不从未滤波端取电）
- [ ] 铺铜后已放置足够GND缝合孔，空白区域无遗漏
- [ ] 泪滴已添加（类滴后需重建铺铜再做DRC）
- [ ] 差分线线长差在5mil以内

---

## K. 丝印专项审查 [来源: Expert电子实验室+荣洋电子RYDZ]

- [ ] 正面和背面丝印均已检查（底层丝印不要遗漏）
- [ ] 排针引脚标注清晰（引脚功能/IO编号）
- [ ] 电源引脚标注电压值（5V、3V3、GND）
- [ ] 开关方向有标识（圆点/箭头标注"开"方向）
- [ ] 丝印未覆盖焊盘（至少1mm间距）
- [ ] 板名、版本号、引脚定义表已标注在背面丝印

---

## L. 竞赛/教学场景附加审查 [来源: Expert电子实验室强化篇51核心板]

- [ ] 元器件平行或垂直排列，无横竖混放
- [ ] 板面分布均匀，无大片空白
- [ ] 接口/按键/排针在板子边缘，便于操作
- [ ] 所有贴片元件在同一面（单面贴片），避免双面焊接困难
- [ ] 板框有圆角（至少2mm），防止划伤
