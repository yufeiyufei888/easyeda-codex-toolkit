# 原理图设计与审查

本技能提供嘉立创EDA原理图设计的全流程支持，区分两种工作模式。

---

## 模式判断（首先执行）

在每次对话开始时，根据用户输入判断当前属于哪种模式：

| 用户意图信号 | 判定模式 |
|---|---|
| "帮我画"、"设计一个"、"这个电路怎么做"、"器件选什么"、描述新需求 | **设计模式** |
| "审查"、"检查"、"帮我看下"、"有没有问题"、"DRC报错"、给出已有工程 | **审查模式** |

如果用户意图不明确，主动询问："你是想**从头设计**一个新电路，还是**审查检查**一个已有的原理图工程？"

## 设计模式

### 设计原则

- 每一步完成后向用户确认再进入下一步，避免返工
- 方案选型时给出 2-3 个选项，标注各自的优缺点和适用场景
- 涉及具体芯片/器件时，优先查阅其数据手册而非凭记忆猜测
- 优先使用嘉立创EDA库中可采购的器件（通过立创商城引擎搜索）

---

### Step 1：需求分析

**目标**：明确要设计什么电路模块，将功能需求转化为技术指标。

**执行动作**：
1. 与用户确认产品的功能列表、使用场景、供电方式（电池/市电/USB）
2. 将功能需求转化为可量化的技术指标：
   - 输入/输出电压范围、电流需求
   - 信号频率/带宽、精度要求
   - 接口类型与数量（GPIO、UART、SPI、I2C、ADC、PWM等）
   - 物理尺寸约束、成本约束、功耗约束
3. 将需求按功能模块拆分（如：电源模块、主控模块、驱动模块、传感器模块、通信模块）
4. 画出模块框图（文字描述即可），标注模块间的信号流和电源流

**完成标准**：
- [ ] 用户确认功能列表完整
- [ ] 各模块的关键技术指标已明确
- [ ] 模块框图已确认

**工程化设计文档**（复杂项目推荐，来源：Expert入门篇P8、RYDZ智能车）：

在需求分析阶段同步建立三份设计文档，后续原理图绘制以这些文档为蓝图：

- **系统框图(System Diagram)**：描述功能模块及模块间通信方式（如 UART/SPI/I2C），用矩形框+箭头表示信号流和电源流。例：`电池→DCDC(12V→5V)→LDO(5V→3.3V)→MCU ←→ TB6612 ←→ 电机`
- **电源树(Power Diagram)**：描述各路电源如何产生和分配，标注电压/电流/来源。典型智能车电源链：`12V输入 → DCDC → 5V → (LDO→3.3V供MCU) + (直供TB6612的VM)`
- **GPIO分配表**：多引脚主控（≥48pin）建议列出所有GPIO的规划用途，格式：`引脚名 | 功能 | 方向 | 备注`，避免布线时发现外设冲突
- **电源上电时序**：复杂系统（FPGA/DSP/多电压域MCU）需确认上电顺序，不满足时序可能导致芯片死锁

**常见问题引导**：
- "这个产品用什么供电？电池还是USB？电压是多少？"
- "对体积有要求吗？是用开发板还是自己画板？"
- "预算敏感吗？是否需要考虑国产替代？"

### Step 2：器件选型

**目标**：为每个功能模块选定具体器件型号及封装。

**执行动作**：
1. **主控芯片选型**（如有）：
   - 统计所需外设：GPIO数量、UART/SPI/I2C路数、ADC通道数及分辨率、定时器/PWM路数、DAC需求
   - 评估处理能力：是否需要FPU/DSP、Flash/RAM容量
   - 考虑开发生态：是否有成熟SDK/教程/社区支持
   - 常用参考：GD32F450（接口丰富）、STM32F103C8T6（经典入门）、ESP32-C3（WiFi/蓝牙）、CW32F030（国产低成本）

2. **电源方案选型**：
   - 线性稳压（LDO）：适用于小电流（<500mA）、压差小的场景，电路简单、纹波小
   - 开关电源（DCDC）：适用于大电流、高压差的场景，效率高但PCB布局要求高
   - 关键参数：输入电压范围、输出电压、最大输出电流、静态电流（电池供电场景重点关注）
   - 电池供电必选低压差LDO（AMS1117压差约1.1V，3.9V锂电池无法可靠输出3.3V）

3. **关键器件参数计算与选型**（以DCDC Buck为例）：
   - 确认Vin_range、Vout、Iout_max
   - 关注规格书中：Rds(on)（导通损耗）、开关频率、电流限值、EN阈值、软启动
   - 外围器件：电感量计算 L = (Vin-Vout) × D / (ΔIL × fsw)；输入/输出电容选低ESR陶瓷电容(X7R)

4. **运放选型**（如有模拟电路）：
   - 关键参数：增益带宽积(GBW)、压摆率、轨对轨特性（单电源重点关注输出轨）、失调电压（精密小信号必看）

5. **封装选择原则**：
   - 手工焊接 → 0805/0603（贴片阻容），SOP/LQFP（芯片）
   - 机器贴片 → 0402/0202，QFN/BGA
   - 功率器件 → 关注热阻（θJA），预留散热铜皮

**完成标准**：
- [ ] 所有关键器件的型号和封装已确定
- [ ] BOM成本在预算范围内
- [ ] 关键器件可通过立创商城正常采购（非停产/断供）

**推荐工具**：在嘉立创EDA中使用"立创商城"搜索引擎（Shift+F或下方库搜索按S），筛选条件：封装 + 品牌 + 库存状态。

### 数据手册阅读方法

> 完整方法论见 `references/datasheet-methodology.md`。以下为核心要点。

**原则**：不需要逐页通读数据手册（10~100+页），先定位关键章节。电路设计不意味着每个电路都从零设计——优先参考厂家示例电路，在其基础上结合自身应用场景修改。

**快速定位三板斧**（以TPS5450为例的11部分框架中的核心3部分）：
1. **引脚配置和功能** → 引脚图+引脚功能表格（名称/编号/I-O类型/说明），设计原理图的核心依据
2. **电气特性表格** → 确认供电电压/IO电平/ESD等级/建议工作条件，确保设计不突破电气极限
3. **典型应用电路 + 选型公式** → 大部分实际电路 = 厂家示例电路 + 场景适配修改；代入自身参数计算外围器件值（如电感量、反馈电阻比）

**省时阅读策略**：
| 优先级 | 部分 | 阅读方式 |
|--------|------|----------|
| 极高 | 引脚配置、典型应用电路 | 逐字阅读，照做 |
| 高 | 特性(Features)、电气规格、应用(Applications) | 用于快速选型确认 |
| 中 | 详细说明、功能框图 | 理解芯片内部行为逻辑 |
| 低/跳过 | 修订历史、器件和文档支持 | 不关注 |
| 按需 | PCB布局建议、机械封装图 | 无现成封装时按图自绘 |

**初学者建议**：
- 多读多练，有空就下载数据手册当"小说"读，熟悉常见芯片的文档结构
- 学会利用AI辅助：截图发给AI询问"这个CE引脚的电压范围是多少"等具体参数
- 学好英语：大部分芯片厂商为国外厂商，数据手册为英文

### Step 3：原理图绘制指导

**目标**：指导用户在嘉立创EDA中完成原理图绘制。

**执行动作**：

1. **图纸设置**：
   - 大型工程建议右键新建多个图页，按功能分页（如：电源、主控、驱动、传感器、通信）
   - 设置图纸尺寸（默认A4，可切换A3/A2）

2. **器件放置**：
   - 从左侧常用库放置基础器件（R/C/L/二极管/晶体管），下拉切换封装
   - 库搜索（快捷键S）：使用"立创商城"引擎获取带供应商编号的真实器件
   - 放置后在右侧属性面板确认符号、封装、3D预览

3. **连接方法选择**：
   - 近距离引脚 → **导线（Alt+W）**：从小灰点连到小灰点
   - 远距离/跨区域 → **网络标签（Alt+N）**：名称完全相同即连接
   - 成组信号 → **总线（Alt+B）**：命名格式 `PA[0..15]`，挂载网络标签自动递增
   - 电源网络 → **电源端口**（VCC/GND/5V等标识符）
   - 多图页跨页 → **跨页连接标识**：右键→关联可快速跳转

4. **模块化与注释**：
   - 使用导线和网络标签时，用矩形框/文本标注模块功能
   - 未使用引脚 → 放置**非连接标识符（红叉）**，避免DRC报"引脚未使用"
   - 差分信号 → 命名遵循 `_P/_N` 或 `_DP/_DN` 结尾，系统自动识别
   - 图纸信息栏支持动态参数（在明细表中新增，右侧属性面板填写）

5. **命名规范**：
   - 网络标签用有意义的功能名（如 `USB_DP`、`MOTOR_A_IN1`）
   - 差分对：`USB_DP`/`USB_DN` 或 `XXX_P`/`XXX_N`
   - 总线：`PA[0..15]`
   - 电源：`VCC_5V`、`VCC_3V3`、`VBAT`、`VREF`

6. **注释的多种类型**（来源：Expert入门篇P8）：
   - 模块功能说明文本（中文矩形框标注各模块用途，如"电源电路"、"MCU最小系统"）
   - 元件特殊标记：NC（不连接）、NM/NF（不安装）、0R（0欧电阻=短路/跳线）
   - 关键参数标注：LDO最大输出电流、晶振频率、电容耐压等，无法从符号直接读取的参数必须标注
   - 注意事项标注：如"ESP32启动时IO0需低电平"、"此引脚不可接5V"
   - 配置表格：如快充诱骗电压对应表
   - 版本号/日期/作者/公司logo

7. **网络标签命名进阶**（来源：Expert入门篇P8、RYDZ智能车）：
   - 推荐格式：`元件名_信号功能`（如 `MPU6050_SDA`、`OLED_SCL`、`TB6612_PWMA`）
   - 避免重复标签名，防止意外的电气连接
   - 电源网络：除VCC/GND外，区分来源用 `+5V`、`VCC_5V`、`VCC_3V3`、`VIN`、`VBAT`、`VREF`
   - 固定输出电压芯片：网络名用通用名（如 `VCC`），非具体电压值，背面丝印注明对应关系

**完成标准**：
- [ ] 所有器件的符号正确放置在图纸上
- [ ] 所有电气连接已完成（导线/网络标签/电源端口）
- [ ] 网络标签命名清晰有意义
- [ ] 未使用引脚已标注非连接标识符

### Step 4：自查与DRC检查

**目标**：在转换PCB前发现并修复原理图中的所有问题。

**执行动作**：
1. 运行DRC检查：设计 → 检查DRC（或点击左下方DRC按钮）
2. 处理报错（按严重程度）：

| 错误类型 | 常见原因 | 修复方法 |
|---|---|---|
| 网络标签未连接任何引脚 | 标签未对准导线/引脚（右下角白色十字未对准） | 将标签正确放置在导线或引脚上 |
| 该网络连接不完整 | 网络仅连接了一个引脚 | 确认是否需要两个以上连接点，设计需求可忽略 |
| 导线存在多个网络标签 | 同一条导线上放了不同名标签（VCC和GND等） | 删除多余标签；若需短接不同网络，使用短接标识符 |
| 位号重复 | 两个器件位号相同（如两个U2.1） | 重新分配位号 |
| 引脚悬空 | 引脚无连接 | 确认是设计需求则加非连接标识符，否则补连接 |
| 不能组成完整多部件元件 | 多Part器件仅放置了部分 | 放置全部Part |

3. 检查引脚方向：符号创建时引脚圆圈端必须朝外，否则导线无法建立有效连接
4. 确认没有用画布图形工具画的"伪符号"（没有电气属性，必须在符号编辑器中正式创建）
5. **DRC质量保证思维**（来源：Expert入门篇P12、RYDZ智能车）：
   - DRC（Design Rule Check）= 硬件开发的"编译检查"——类似软件编译通过才能烧录，DRC通过才能发板打样
   - **实时DRC**：嘉立创EDA设计菜单中勾选"实时DRC检测"，画图过程中即时报错，不要等全部画完再查
   - 警告级（如"元件属性与供应商编号不匹配"）：逐条评估设计需求，可忽略的关闭对应检查项
   - 双重DRC：原理图DRC + PCB DRC，两者都通过才是合格的工程文件
   - 每次重建铺铜或添加泪滴后需重新执行DRC（顺序不可乱：铺铜→泪滴→重建铺铜→DRC）

**完成标准**：
- [ ] DRC检查无红色错误（设计需求允许的除外）
- [ ] 黄色警告已逐条确认可接受
- [ ] 所有差分对在差分对管理器中正确生成

### Step 5：转换PCB准备

**目标**：将原理图正确转换到PCB，为布局布线做准备。

**执行动作**：
1. 设计 → 更新/转换原理图到PCB（快捷键 Alt+I）
2. 勾选"包含设计规则"——将差分对、网络类、等长网络组等规则导入PCB
3. 点击"应用修改"，确认无错误
4. 使用**布局传递（Ctrl+Shift+X）**：在原理图中框选某区域器件→PCB中自动选中对应器件，便于分模块布局
5. 使用**交叉选择（Shift+X）**：原理图选中→PCB高亮，快速定位

**完成标准**：
- [ ] 所有器件成功转换到PCB，封装正确
- [ ] 网络连接关系正确导入
- [ ] 设计规则（差分对/网络类）已导入

### Step 5 补充：PCB设计全局观

原理图完成后，进入PCB设计的完整管线（来源：Expert入门篇P12、RYDZ系列）：

```
原理图设计 → PCB布局 → PCB布线 → DRC检查 → 导出Gerber → 下单打样
```

- **布局决定布线**：布局是布线的前提——元件位置决定了走线难度和信号质量，不要跳过布局直接布线
- **分模块布局**：同一功能电路放在同一区域，利用"布局传递（Ctrl+Shift+X）"将原理图中的模块结构映射到PCB
- **先预布局后上板**：先在PCB空白区域按模块预布局各组电路（如电源区、MCU区、接口区），再整体拖入板框内
- **布局优先级**：固定位置件（螺丝孔、接口、主控）→ 大尺寸模块 → 离散元件（滤波电容就近放）
- **三维意识**：PCB是二维绘图，但不能忽略元件高度——屏幕下方不能放高元件，接口不要被高元件遮挡
- 嘉立创免费打样规则：板子尺寸≤10×10cm，最小线宽/线距≥6mil（非4mil，确保多厂商兼容），每月2次

> PCB布局布线、差分对、丝印的详细规范见 `references/pcb-layout-guidelines.md`。

### 重要约束

> **审查模式下只列出问题与建议，不直接修改工程文件。** 除非用户明确说"帮我改一下"、"按你的建议修改"，否则所有输出仅以文字清单呈现。

### Step 1：电气规则审查

**检查内容**：

1. **电源网络完整性**：
   - 所有VCC/GND引脚是否都有正确的电源连接
   - 不同电压域之间是否有隔离（如5V与3.3V之间是否误连）
   - 电源端口的名称是否与实际电压一致（标注5V的端口是否接了3.3V）
   - 去耦电容是否放置且靠近对应芯片电源引脚

2. **信号连接正确性**：
   - UART：TXD→RXD交叉连接是否正确
   - SPI：MOSI/MISO/SCK/CS对应关系是否正确
   - I2C：SDA/SCL是否接了上拉电阻（典型值4.7KΩ，模块内置则可省略）
   - USB：DP/DN差分对是否正确，CC引脚（Type-C）是否处理
   - 晶振：负载电容是否匹配晶振规格，确认是有源还是无源晶振

3. **引脚冲突**：
   - 是否有多个输出引脚驱动同一网络（总线冲突）
   - 输入引脚是否悬空（可能导致不稳定电平）
   - GPIO电平是否匹配（3.3V MCU驱动5V器件需电平转换）

4. **保护电路**：
   - 电源输入是否有防反接保护（二极管/PMOS）
   - 对外接口是否有ESD/TVS保护
   - 高压测量场景是否有隔离措施
   - USB接口是否有自恢复保险丝（PTC），防止短路烧毁电脑USB口

5. **特殊MCU检查**（来源：Expert强化篇51核心板、RYDZ MSPM0）：
   - **STC89C52 P0口**：上电复位后为开漏输出，作普通IO必须外接10K上拉电阻（P1/P2/P3为准双向口无需）
   - **STC89C52 LED驱动**：灌电流能力远大于拉电流，LED应阴极接IO口（灌电流模式），阳极接电源
   - **MSPM0G PA2引脚**：数据手册要求100K下拉电阻精度±0.1%，用1%精度电阻会导致芯片工作异常
   - **MSPM0G VCORE引脚**：内部核心电压输出，仅接470nF电容到GND，不得接任何其他电路
   - **BSL/BOOT引脚**：如IO资源充足尽量不用（如MSPM0的PA18），可能在软件开发中引发异常

---

### Step 2：设计规范审查

**检查内容**：

1. **原理图可读性**：
   - 网络标签命名是否清晰有意义（避免 `Net_001` 类的自动命名）
   - 模块功能是否有文字标注/矩形分区
   - 信号流向是否从左到右、从上到下
   - 图纸信息栏是否填写完整
   - 重要参数是否直接标注在原理图上（非仅写在BOM中），如最大电流、晶振频率
   - 注意事项是否标注（如启动引脚电平要求、最大电流限制）
   - 多图页工程前几页是否为系统框图/电源树/GPIO分配表

2. **模块化**：
   - 大型工程是否分多图页
   - 跨页连接标识是否清晰
   - 复用电路是否使用层次原理图/网络端口

3. **命名规范**：
   - 位号是否有重复
   - 差分对命名是否遵循 `_P/_N` 规范
   - 总线命名是否规范 `NAME[start..end]`

4. **封装匹配**：
   - 原理图符号与PCB封装是否对应（引脚号、引脚排列）
   - 功率器件封装是否与功耗匹配（热阻是否满足）

---

### Step 3：器件选型审查

**检查内容**：

1. **参数裕量**：
   - 电容耐压：陶瓷电容直流偏置降额（X7R在额定电压50%时容值可能降低60%+）
   - 电阻功率：实际功率不应超过额定功率的50%
   - IC结温：TJ = TA + PD × θJA，确认不超过最大结温
   - 电感饱和电流：峰值电流不超过饱和电流的80%

2. **可采购性**：
   - 器件是否在立创商城有库存
   - 是否有停产/断供风险
   - 封装是否为常用规格（非特制非标）

3. **成本与替代**：
   - 是否有价格更优的国产替代
   - 多种阻值的电阻是否可以合并为同一种以减少BOM种类
   - LDO/DCDC选型是否匹配实际功耗（避免LDO承担过大电流导致严重发热）

4. **数据手册核对**：
   - 引脚功能是否与数据手册一致（不要凭经验假设引脚排列）
   - 最大/最小工作电压是否覆盖实际供电范围
   - EN/STBY等控制引脚电平逻辑是否正确

- [ ] 电感额定电流 > 峰值电流

- [ ] DCDC电感量/频率匹配
- [ ] MOSFET的Vgs(th)与驱动电压兼容
- [ ] 运放输入共模范围覆盖信号范围

### 设计规范检查项

- [ ] 无重复位号
- [ ] 差分对命名规范（_P/_N）
- [ ] 网络标签有意义（非Net_xxx）
- [ ] 图纸信息栏完整
- [ ] 信号流清晰（左→右，上→下）
- [ ] 电源端口名称与实际电压一致
- [ ] 跨页连接标识符正确对应

### 常见错误Top 25

1. 网络标签浮空——标签十字未对准导线/引脚
2. 导线多重标签——同导线多个不同名网络标签
3. 电源端口名称错误——5V端口实际接了3.3V
4. 晶振负载电容不匹配——未查数据手册凭经验取值
5. 芯片电源引脚遗漏——某侧VCC/GND未连接
6. UART TX/RX未交叉——同名直连导致无法通信
7. 封装引脚不对应——原理图符号与PCB封装引脚排列不一致
8. 符号引脚方向反了——圆圈端在内侧导致导线无法有效连接
9. LDO压差不足——电池供电场景选错LDO型号
10. 未区分有源/无源晶振——接法完全不同
11. 电容耐压不足——未考虑直流偏置容值降额
12. I2C漏上拉电阻——开漏输出必须外接上拉
13. 功率器件未考虑散热——无散热铜皮空间
14. EN引脚悬空——芯片可能不工作或状态不确定
15. Type-C CC引脚悬空——不处理可能导致无法供电
16. 模拟/数字地未隔离——噪声串扰影响模拟精度
17. 电机/继电器无续流二极管——关断瞬间高压击穿驱动管
18. 输入无ESD保护——外部接口易受静电损坏
19. GPIO直驱大负载——超出IO最大拉/灌电流
20. 原理图"伪符号"——用图形工具画的符号无电气属性
21. 51单片机P0口未加上拉——开漏输出无法输出高电平（P1/P2/P3无需）
22. 51单片机LED拉电流驱动——应使用灌电流方式（阴极接IO口，阳极接VCC）
23. MSPM0 PA2下拉电阻精度不足——必须±0.1%，用1%精度芯片工作异常
24. 钽电容极性接反——杠杠侧=正极（与铝电解相反！），接反可能爆炸
25. Type-C仅接单个CC下拉——正反插时其中一个CC悬空，充电器可能拒供电

## 项目经验速查

基于真实项目经验的快速决策参考：

- **选MCU不清楚选哪款** → 统计外设需求（GPIO/UART/SPI/ADC/PWM数量）→ 优先选有成熟教程的型号
- **电池供电产品** → 用低压差LDO（非AMS1117）+ 关注静态电流 + ADC电量检测
- **高压测量/测试笔** → 电气隔离（BLE无线通信替代USB）+ 输入钳位保护
- **电机驱动** → 电机电源直连电池（不经LDO）+ 电机端子并联104电容 + 续流二极管
- **DCDC布局** → 输入电容必须紧靠Vin和GND引脚（否则寄生电感导致电压尖峰击穿MOSFET）
- **晶振不起振** → 先查数据手册确认晶振类型（有源/无源）+ 负载电容是否匹配
- **成本优化** → 合并BOM物料种类（用两颗10K代替20K，用已有的900K代替1M）
- **DCDC电感选型** → 务必用一体成型电感（屏蔽式），开放式电感有磁通量泄漏会导致EMI问题（来源：RYDZ智能车）
- **MCU核心板供电** → 必须用LDO而非DC-DC，DC-DC纹波会导致芯片工作不稳定（来源：RYDZ MSPM0）
- **Type-C仅供电场景** → 选6pin即可，CC1/CC2各接5.1K下拉到GND（告诉充电器"只要5V"）；16pin/24pin不必要（来源：Expert强化篇）
- **丝印=硬件注释** → 背面丝印写清电压对应关系、引脚定义、注意事项，面向队友和后续调试（来源：RYDZ智能车）
- **滤波电容放置** → 先大后小：先经过大电容（如10μF）再经过小电容（如0.1μF），靠近引脚；空间不够小电容可放底层（来源：Expert强化篇）
