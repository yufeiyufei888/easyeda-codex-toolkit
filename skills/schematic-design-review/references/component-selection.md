## 电阻

### 阻值选择
- 常用阻值系列：E24（5%精度）、E96（1%精度）
- 优先从此系列中选择，避免特殊阻值增加采购难度

### 功率降额
- 实际功耗 ≤ 额定功率 × 50%
- 常见封装对应功率：
  - 0201: 1/20W (0.05W)
  - 0402: 1/16W (0.063W)
  - 0603: 1/10W (0.1W)
  - 0805: 1/8W (0.125W)
  - 1206: 1/4W (0.25W)
  - 1210: 1/2W (0.5W)
  - 2512: 1W

### 精度选择
- 分压/反馈/采样 → 1%或0.1%精密电阻
- 上拉/下拉/限流 → 5%即可
- 电流检测（检流电阻） → 1%或0.1%，注意温漂（ppm/℃）

### BOM优化技巧
用已有阻值替代非标阻值：
- 两颗10K串联 = 20K（减少物料种类）
- 两颗10K并联 = 5K
- 已有的900K可替代1M（精度要求不高的场景）

### 电阻读值方法（来源：Expert入门篇P4）

**插件色环电阻**：
- 四环制：前两环=数值，第三环=倍率(10^n)，第四环=误差（金=±5%，银=±10%）
- 五环制：前三环=数值，第四环=倍率(10^n)，第五环=误差（棕=±1%，红=±2%）
- 色码表：黑(0)棕(1)红(2)橙(3)黄(4)绿(5)蓝(6)紫(7)灰(8)白(9)

**贴片电阻**：
- 三位数标法（±5%精度）：前两位有效数字+第三位10^n。例：`104` = 10×10^4 = 100KΩ
- 四位数标法（±1%精度）：前三位有效数字+第四位10^n。例：`5112` = 511×10^2 = 51.1KΩ
- 带R标记：R=小数点。例：`R006`=0.006Ω，`1R5`=1.5Ω，`0R`=0Ω（跳线/短路用）

**色环电感**：读法同色环电阻（四环制），单位μH。例：红红棕金 = 22×10^1 = 220μH ±5%

## 电容

### 电容类型选型

| 类型 | 容值范围 | 耐压 | 特点 | 适用场景 |
|------|---------|------|------|---------|
| MLCC (X7R) | pF~10μF | 6.3V~100V | 体积小、ESR低、温度稳定性好 | 去耦、滤波、旁路 |
| MLCC (C0G/NP0) | pF~0.1μF | 16V~100V | 极高稳定性、低损耗 | 振荡器、滤波器、RF |
| MLCC (Y5V) | 0.01μF~100μF | 6.3V~50V | 温漂极大，不推荐 | 尽量避免使用 |
| 铝电解 | 0.1μF~10000μF | 6.3V~450V | 大容量、有极性、ESR较高 | 电源滤波、储能 |
| 钽电容 | 0.1μF~1000μF | 2.5V~50V | 大容量、低ESR、有极性 | 空间受限的电源滤波 |
| 固态电解 | 1μF~2700μF | 2.5V~25V | 极低ESR、长寿命 | 高频电源滤波 |

### 直流偏置降额（MLCC关键知识）

X7R/X5R陶瓷电容在施加直流电压后，实际容值会显著下降：
- 额定电压50%时，容值可能只剩40%~60%
- 额定电压接近100%时，容值可能只剩20%~30%

**选型规则**：电容耐压 ≥ 工作电压 × 2（针对X7R/X5R）

### 常见去耦电容组合
- 每个芯片电源引脚：100nF (X7R, 0603/0402)
- 每个DCDC输入：10μF~22μF (X7R) + 可选100μF电解
- 每个DCDC输出：22μF (X7R) + 可选100μF电解
- 晶振负载电容：按数据手册，通常12pF~22pF (C0G/NP0)

### 电容封装与耐压
- 0402: 通常最高25V
- 0603: 通常最高50V
- 0805: 通常最高100V
- 1206: 通常最高200V
- 封装越大，同等耐压可选容值越大

### 电容读值方法（来源：Expert入门篇P4）

**插件铝电解电容**：
- 白色竖线/阴影带 = 负极；容值和耐压直接印在封装上（如 `470μF 35V`），默认单位μF
- 长引脚=正极，短引脚=负极

**贴片铝电解电容**：
- 黑色小半圆标记 = 负极；容值印在顶部

**钽电容（重要！极易出错）**：
- 三位数标法同贴片电阻，但单位是 **pF**（不是μF！）。例：`226` = 22×10^6 pF = 22μF
- **极性识别（与铝电解相反！）**：杠杠/色带侧 = **正极**（铝电解横杠=负极）
- S级=正极，D级=负极
- 耐压字母对照表（需查数据手册）：常见如 V=35V，E=25V，C=16V
- **警告**：钽电容极性接反会爆炸！务必确认杠杠侧=正极

**CBB/涤纶电容**：
- 三位数读法同贴片电阻，单位pF。例：`684` = 68×10^4 pF = 0.68μF；`104` = 0.1μF

**涤纶电容标注解析**（如 `2A223G`）：
- `223` = 22×10^3 pF = 0.022μF
- `G` = 精度 ±5%（J=±5%，K=±10%，M=±20%）
- `2A` = 耐压代码（A=1V，2=10^2，即100V耐压）

**X电容/安规电容**：封装上直接标注（如 `0.01μF 275V`）

**瓷片电容**：无耐压标注时默认耐压 50V（工程经验）

### 多类型电容并联滤波策略（来源：Expert入门篇P4、RYDZ智能车）
- MLCC（中高频滤波好，容值偏低）+ 钽电容/铝电解（容值高，中低频滤波）= 1+1>2的宽频滤波效果
- 典型搭配：DCDC输入/输出各用 10μF MLCC + 100μF电解 + 100nF MLCC
- 布局原则：**先大后小**——电流先经过大电容（如10μF电解），再经过小电容（如100nF MLCC），小电容最靠近芯片引脚

## 电感

### DCDC电感选型

**电感量计算公式（Buck）**：
```
L = (Vin - Vout) × D / (ΔIL × fsw)
```
其中 D = Vout / Vin，ΔIL 通常取 Iout_max × 30%

**关键参数**：
- 电感量（μH）：决定纹波电流大小
- 饱和电流（Isat）：电感量下降30%时的电流，峰值电流必须小于此值
- 额定电流（Irms/Idc）：温升限制的电流，留30%+裕量
- DCR（直流电阻）：越小效率越高
- 屏蔽/非屏蔽：屏蔽电感EMI更小，推荐

**常见DCDC电感参考值**（以1MHz开关频率为例）：
| 输出电流 | 推荐电感量 | 推荐尺寸 |
|---------|-----------|---------|
| <500mA | 4.7μH~10μH | 2520/3225 |
| 500mA~1.5A | 3.3μH~6.8μH | 3225/4030 |
| 1.5A~3A | 2.2μH~4.7μH | 4030/5030 |
| 3A~6A | 1μH~3.3μH | 5030/6045 |

### 电感读值方法（来源：Expert入门篇P4）
- **贴片功率电感**：三位数标法同贴片电阻，单位μH。例：`331` = 33×10^1 = 330μH；`1R5` = 1.5μH
- **色环电感**：读法同色环电阻（四环制），单位μH
- **工字电感/环形电感**：参数通常直接印在封装上

### 一体成型电感 vs 开放式电感（来源：RYDZ智能车）
| 类型 | 特点 | 使用规则 |
|------|------|----------|
| 一体成型电感（屏蔽式） | 磁路闭合，无磁通量泄漏，EMI低 | **DCDC首选**，下方无需禁止铺铜区 |
| 开放式电感（磁芯裸露） | 有磁通量泄漏，产生电磁干扰 | 不推荐DCDC使用；若必须用，电感正下方顶层+底层均设禁止铺铜区 |

- **选型铁律**：DCDC电路务必选用一体成型电感，否则电路可能出现"莫名其妙的问题"
- 电感额定电流需留余量：≥ 芯片输出电流 × 1.5（如3A输出选4.5A额定电感）

### 磁珠 vs 电感
- **磁珠（Ferrite Bead）**：在特定频率下呈现高阻抗，用于EMI抑制，不可用于储能/滤波
- **电感**：用于储能（DCDC）和LC滤波
- **两者不可互换**

| 类型 | 符号特征 | 典型应用 | 选型要点 |
|------|----------|----------|----------|
| 普通二极管 | 标准符号 | 整流 | 1N4007 (1A/1000V) |

| 发光二极管(LED) | 填充+箭头向外 | 指示/照明 | 限流电阻：R=(VCC-Vf)/If |

| 变容二极管 | 二极管+电容符号 | 调谐 | |

| TVS管 | -- | ESD/浪涌保护 | Vrwm>工作电压, Vclamp<耐受电压 |

### 二极管正负极识别（来源：Expert入门篇P5）

| 封装类型 | 识别方法 |
|----------|----------|
| 插件LED | "大红旗"=负极，"小红旗"=正极；短引脚=负极，长引脚=正极 |
| 贴片LED(0805等) | 底部绿色三角形由正极指向负极；正面绿色小圆点=负极 |
| 贴片二极管(SOD-323等) | 浅色竖线端=阴极（负极） |
| 插件二极管 | 黑色竖线/色环端=阴极（负极） |
| 钽电容注意 | 杠杠侧=**正极**（与二极管/铝电解相反！） |

### 关键选型规则
- 防反接：肖特基（Vf低，发热小），注意额定电流；续流二极管额定电流留50%余量（如3A输出选5A二极管）
- 续流二极管（电机/继电器线圈）：肖特基或开关二极管，反向耐压 ≥ 电源电压 × 2
- TVS管：Vrwm > 被保护线路正常工作电压，Vclamp < 被保护器件最大耐受电压
- 硅管导通压降0.6~0.8V，锗管0.2~0.3V；肖特基约0.2~0.3V

## 三极管（BJT）

> 来源：Expert入门篇P5

### NPN vs PNP 判断法
"箭头由P指向N"：符号中发射极箭头向外 = 内部P材料→外部N材料 → **NPN**；箭头向内 → **PNP**。

三个极：集电极C（Collector）、基极B（Base）、发射极E（Emitter）

### 三种工作状态

| 状态 | 发射结 | 集电结 | IC与IB关系 | 等效 |
|------|--------|--------|------------|------|
| 截止区 | 反偏 | 反偏 | IC≈0（IB=0） | 开关断开 |
| 放大区 | 正偏 | 反偏 | IC = β × IB | 放大器 |
| 饱和区 | 正偏 | 正偏 | CE间近似短路 | 开关闭合 |

- 硅管B-E导通压降约0.6~0.7V

### 典型应用

**开关驱动负载**（单片机IO驱动力不足时）：
```
[VCC] → [负载(如灯泡/继电器)] → [NPN集电极C]
[MCU GPIO] → [限流电阻 1K~10K] → [NPN基极B]
[NPN发射极E] → GND
```
- 基极限流电阻必须加，否则烧坏三极管或MCU引脚
- 感性负载（继电器/电机）必须并联续流二极管

**信号放大**：
```
[VCC] → [集电极电阻Rc] → [NPN集电极C] → [耦合电容] → [输出]
[小信号] → [耦合电容] → [基极偏置] → [NPN基极B]
[NPN发射极E] → [Re] → GND
```

### 封装与引脚识别
- TO-92（插件小功率）：平面朝自己，从左到右为 E-B-C 或 C-B-E（**务必查数据手册，不同型号定义不同**）
- SOT-23（贴片）：常见排列 1=B 2=E 3=C
- TO-220（功率管）：常用于大电流驱动

## MOSFET

### NMOS vs PMOS

| 特性 | NMOS | PMOS |
|------|------|------|
| 导通条件 | Vgs > Vth | Vgs < -Vth |
| 应用 | 低端开关、H桥下管 | 高端开关、电源开关 |
| 导通阻抗 | 同规格下Rds(on)更低 | 同规格下Rds(on)较高 |
| 驱动 | 源极接地，容易驱动 | 源极接电源，需要电平转换 |

### 关键参数
- **Vds(max)**：漏源耐压，留30%+裕量
- **Vgs(th)**：阈值电压，确保逻辑电平能完全开启
  - 3.3V逻辑驱动：选Vgs(th) ≤ 1.5V的"逻辑电平MOSFET"
  - 5V逻辑驱动：选Vgs(th) ≤ 2.5V
- **Rds(on)**：导通电阻，决定导通损耗（P = I² × Rds(on)）
- **Qg（总栅极电荷）**：影响开关速度，PWM高频场景选Qg小的
- **封装**：
  - 小信号 SOT-23 (<=200mA)
  - 中功率 SOT-89/TO-252 (<=5A)
  - 大功率 TO-220/TO-263/DFN (5A+)

### 常用型号参考
| 型号 | 类型 | Vds | Id | Vgs(th) | Rds(on) | 封装 |
|------|------|-----|-----|---------|---------|------|
| SI2302 | NMOS | 20V | 2.8A | 0.5~1.2V | 70mΩ | SOT-23 |
| SI2301 | PMOS | -20V | -2.8A | -0.5~-1.2V | 110mΩ | SOT-23 |
| AO3400 | NMOS | 30V | 5.8A | 0.7~1.4V | 28mΩ | SOT-23 |
| AO3401 | PMOS | -30V | -4.2A | -0.7~-1.4V | 65mΩ | SOT-23 |
| IRFZ44N | NMOS | 55V | 49A | 2~4V | 17.5mΩ | TO-220 |
| IRF540N | NMOS | 100V | 33A | 2~4V | 44mΩ | TO-220 |

### 封装与功率等级对应（来源：Expert入门篇P5、RYDZ）

| 封装 | 典型电流范围 | 典型耐压 | 适用场景 |
|------|-------------|----------|----------|
| SOT-23 | ≤5A | ≤60V | 小信号开关、单片机IO直驱 |
| SOT-89 | ≤5A | ≤100V | 中功率、有散热焊盘 |
| TO-252(DPAK) | ≤70A | ≤100V | 中功率电机驱动 |
| TO-220 | 可达100A+ | 高压 | 大功率电机驱动，带散热孔安装散热片 |
| TO-263(D2PAK) | 可达100A+ | 高压 | 大功率贴片版TO-220，底部散热焊盘 |
| DFN/PDFN | 视型号 | 视型号 | 高功率密度，底部大面积散热焊盘 |

- SOT-23适用于单片机IO口直接控制的小信号场景（几A、60V以下）
- TO-252适合中等功率电机驱动（如TB6612配合MOS扩流）
- TO-220/TO-263用于大功率电机/加热器等场景

## LDO线性稳压器

### 选型流程
1. 确认 Vin_range、Vout、Iout_max
2. 计算功耗：Pd = (Vin_max - Vout) × Iout × 安全系数
3. 计算结温：Tj = Ta + Pd × θJA，确认 ≤ 125℃
4. 确认压差（Dropout）：Vin_min - Vout ≥ Dropout（电池供电重点检查）

### 关键参数速查
| 参数 | 含义 | 选择原则 |
|------|------|---------|
| 最大输入电压 | 芯片耐压 | ≥ Vin_max × 1.2 |
| 输出电压精度 | 出厂校准精度 | ≤2%一般够用 |
| 压差(Dropout) | Vin-Vout最小值 | 电池供电选低压差型（<300mV） |
| 最大输出电流 | 带载能力 | ≥ Iout × 1.3 |
| 静态电流(Iq) | 芯片自身消耗 | 电池供电选<10μA |
| PSRR | 电源纹波抑制 | 模拟电路选高频PSRR高的 |

### 常用型号参考
| 型号 | Vin(max) | Iout(max) | Dropout | 特点 |
|------|----------|-----------|---------|------|
| AMS1117-3.3 | 15V | 1A | 1.1V | 经典但压差大，不适合锂电池 |
| ME6211C33 | 6V | 500mA | 100mV | 低压差，适合锂电池→3.3V |
| HT7333 | 12V | 250mA | 40mV | 低压差，小电流，静态电流低 |
| SPX3819M5-3.3 | 16V | 500mA | 340mV | 低压差、低噪声 |
| RT9013-33 | 5.5V | 500mA | 250mV | 低压差、小封装 |

### 电池供电特别提醒
- 3.7V锂电池(3.3V~4.2V) → 不可用AMS1117（压差1.1V不够），用ME6211/HT7333
- 多节锂电池串联(7.4V~8.4V) → AMS1117可用，但效率低发热大，大电流改用DCDC
- LDO放在待机通路的MOS管**之后**，避免静态电流额外消耗

### LDO vs DCDC选择依据（来源：RYDZ MSPM0、RYDZ智能车）
| 场景 | 推荐方案 | 理由 |
|------|----------|------|
| MCU核心板供电 | LDO | DCDC纹波会导致芯片工作不稳定 |
| 单片机系统（功耗<500mA） | LDO | 经济实惠，电路简单 |
| 大电流（>1A）、高压差 | DCDC | LDO发热严重（P=(Vin-Vout)×I） |
| 电机/大功率负载 | DCDC | LDO无法提供足够电流且效率极低 |
| 模拟/精密电路 | LDO（选高PSRR） | 低纹波，DCDC噪声影响精度 |
| 电池续航敏感 | DCDC | LDO效率低浪费电池能量 |

### LDO使能引脚(CE/EN)处理（来源：RYDZ智能车）
- CE引脚接到VIN使能芯片，不过大电流，可用细线（如20mil）
- **安全检查**：查数据手册确认CE引脚电压范围。若最大额定电压仅VIN+0.3V，应串联10K电阻到VIN起限流保护
- NC（No Connect）引脚：空载不接，或加"非连接标识符"（红叉）

## DCDC开关电源

### 选型流程
1. 确定拓扑：降压→Buck，升压→Boost，升降压→Buck-Boost
2. 确认 Vin_range、Vout、Iout_max
3. 快速阅读数据手册关键参数（按优先级）：
   - 上下管Rds(on)（决定导通损耗）
   - 开关频率fsw（影响电感体积和EMI）
   - 电流限值（不等于Iout：Ipk = Iout + ΔIL/2）
   - 关断电流/静态电流（电池供电重点关注）
   - EN阈值与迟滞
   - 软启动时间
   - 最大占空比（影响最小压差）
4. 评估效率：重载看Rds(on)，轻载看静态电流

### 外围器件选型
- **电感**：按公式计算电感量，电感饱和电流 > Ipk
- **输入电容**：低ESR陶瓷(X7R)，22μF通常足够，大功率加大
- **输出电容**：陶瓷(低纹波) + 可选电解(动态响应)
- **反馈电阻**：Vout = Vref × (1 + R1/R2)，推荐1%精度

### 常用芯片参考
| 型号 | 拓扑 | Vin范围 | Iout(max) | 频率 | 特点 |
|------|------|---------|-----------|------|------|
| MT3608 | Boost | 2V~24V | 可调开关电流 | 1.2MHz | 经典升压 |
| MP1584 | Buck | 4.5V~28V | 3A | 1.5MHz | 同步Buck |
| MP2315 | Buck | 4.5V~24V | 3A | 500kHz | 同步Buck |
| TPS5430 | Buck | 5.5V~36V | 3A | 500kHz | TI经典 |
| SY8088 | Buck | 2.5V~5.5V | 1A | 1.5MHz | 小封装(SOT23-5) |

### PCB布局关键
- 输入电容必须紧靠芯片Vin和GND引脚（线路寄生电感引起电压尖峰，可击穿MOSFET）
- 电感靠近SW引脚，SW节点铜皮面积足够但不宜过大（EMI）
- 反馈走线远离SW节点（噪声敏感）

## 运算放大器

### 选型关键参数优先级
1. **供电电压范围**：确认是否支持单电源（如3.3V/5V）工作
2. **轨对轨特性**：
   - 输入轨对轨：输入信号可接近电源轨
   - 输出轨对轨：单电源场景最需关注（输出能否接近0V/GND）
3. **增益带宽积（GBW）**：增益 × 信号频率 < GBW（留10倍裕量）
4. **压摆率（Slew Rate）**：输出变化斜率需大于信号最大斜率
5. **失调电压（Vos）**：精密小信号放大必看（选 <1mV 的）
6. **输入偏置电流**：高阻抗传感器选CMOS/JFET输入型
7. **噪声**：音频/传感器前端关注

### 常用运放参考
| 型号 | 通道 | GBW | SR | Vos | 轨对轨 | 特点 |
|------|------|-----|-----|-----|--------|------|
| LM358 | 双 | 1MHz | 0.5V/μs | 3mV | 输出到GND | 经典低成本，非轨对轨输入 |
| LM324 | 四 | 1MHz | 0.5V/μs | 3mV | 输出到GND | 四路版本LM358 |
| TL072 | 双 | 3MHz | 13V/μs | 3mV | 非轨对轨 | JFET输入，音频常用 |
| NE5532 | 双 | 10MHz | 9V/μs | 0.5mV | 非轨对轨 | 低噪声音频 |
| MCP6002 | 双 | 1MHz | 0.6V/μs | 4.5mV | 输入输出轨对轨 | 低成本轨对轨 |
| GS8552 | 双 | 2.5MHz | 1.2V/μs | 5μV | 轨对轨 | 零漂移精密 |
| OPA2340 | 双 | 5.5MHz | 8V/μs | 0.5mV | 输入输出轨对轨 | 高精度轨对轨 |
| SGM8052 | 双 | 250MHz | 100V/μs | 2mV | 输出轨对轨 | 高速视频 |

### 常见运放电路快速设计
- **同相放大器**：Gain = 1 + Rf/Rg
- **反相放大器**：Gain = -Rf/Rg
- **电压跟随器（Buffer）**：输出直接连反相端，Gain = 1，用于阻抗匹配
- **差分放大器**：Vout = (V+ - V-) × Rf/Rg
- **迟滞比较器**：必须加正反馈电阻（不能用普通比较器做触发），迟滞比 = Rh/Rpullup

### 特殊MCU注意事项

**STC89C52系列（51单片机）**（来源：Expert强化篇51核心板）：
- **P0口特性**：上电复位后为"开漏输出"，无法输出高电平。作普通IO使用时，**必须外加10K上拉电阻**（接VCC）
- P1/P2/P3/P4口上电复位后为"准双向口"，无需外加上拉
- **灌电流 > 拉电流**：驱动LED必须阴极接IO口（灌电流模式），阳极接VCC——IO输出低电平时LED点亮
- **LQFP vs DIP**：实际项目推荐LQFP封装（体积小），DIP封装体积大且"不优雅"

**TI MSPM0G系列**（来源：RYDZ MSPM0）：
- **PA2引脚**：必须用**±0.1%精度**的100K下拉电阻到GND。实测用1%精度电阻会导致芯片工作异常。这种高精度电阻较贵（几毛钱/颗）
- **VCORE引脚**：芯片内部核心电压输出，**仅接470nF电容到GND**，不得接任何其他电路。电容紧靠芯片，走线最短
- **PA0/PA1引脚**：可耐受5.5V，通过10K/4.7K/47K电阻上拉到5V或3.3V即可
- **BSL引脚(PA18)**：类似STM32的BOOT引脚，若IO资源充足尽量不用，可能在软件开发中引发异常
- G3507-48pin约7元/颗，G3507-64pin约13元/颗（性能相同仅引脚数不同）

**Type-C接口选型**（来源：Expert强化篇）：
| 引脚数 | USB版本 | 适用场景 | 焊盘特点 |
|--------|---------|----------|----------|
| 6pin | USB 2.0 | 仅供电，不需数据传输 | 简洁 |
| 16pin | USB 2.0 | 供电+USB2.0数据 | GND/VBUS焊盘由两小焊盘合并以增大过流面积 |
| 24pin | USB 3.0/全功能 | 高速数据+快充+视频 | 最复杂 |

- 仅供电场景选6pin即可，16pin/24pin不必要
- CC1/CC2各接5.1K下拉电阻到GND（告诉充电器"我只需要5V，不需要快充"）
- 16pin的Type-C实际只有12个独立功能引脚（A6/A7和B6/B7各两个USB2.0差分对用于正反插）

## 晶振

### 有源晶振 vs 无源晶振

| 特性 | 无源晶振 | 有源晶振 |
|------|---------|---------|
| 引脚数 | 2脚 | 4脚（VCC/GND/OUT/NC） |
| 配套电路 | 需外部负载电容+内部振荡器 | 内部已集成，仅需供电 |
| MCU连接 | 接OSC_IN + OSC_OUT | 仅接OSC_IN（或CLK_IN） |
| 稳定性 | 受PCB/负载电容影响 | 好，内部独立振荡 |
| 成本 | 低 | 高（约2~5倍） |
| 适用 | 一般精度需求 | 下载器/时钟精度要求高的场景 |

### 关键规则
1. **必须先查阅MCU数据手册再选晶振**——确认MCU的时钟输入引脚支持哪种类型
   - 部分MCU仅支持低速无源+高速有源（如STM32G0K6T6）
   - 8MHz无源晶振错误的用在只支持有源的引脚上 → 代码跑不通
2. **负载电容计算**：CL = (C1×C2)/(C1+C2) + Cstray，C1=C2时 CL ≈ C1/2 + Cstray
   - 晶振标称12pF → C1=C2≈22pF（含寄生约3~5pF）
3. **PCB布局**：晶振靠近MCU → 负载电容紧靠晶振 → 晶振下方不布走线 → 周围加禁止铺铜区
4. 省钱方案：用MCU内部RC振荡器（精度约1%）替代外部晶振（精度约20ppm）
