## 电源电路

### 1. LDO降压电路（5V→3.3V）

```
[5V_IN] --- [10μF] --- [LDO] --- [10μF + 100nF] --- [3V3_OUT]
              ||         VIN→VOUT      ||     ||
              GND         GND          GND    GND
```

**设计要点**：
- 输入/输出电容的容量、介质、ESR、直流偏压降额和稳定性窗口按准确LDO数据手册选择，不把10μF+100nF作为跨型号固定值
- 电容尽可能靠近LDO引脚放置
- 是否使用LDO及具体型号取决于电池串数、最低输入、负载、压差、静态电流和最坏热耗散；不能仅以“电池供电”判定，也不能脱离工作点绝对排除某一型号
- LDO发热量：P = (Vin - Vout) × Iout，例如 (5V-3.3V)×500mA = 0.85W

### 2. DCDC Buck电路（以MP1584为例）

```
[Vin] --- [Cin 22μF] --- [MP1584 VIN] --- [SW] --- [L] --- [Cout 22μF] --- [Vout]
                          [EN] ← 上拉/Vin    |         |       |
                          [FB] ←────[R2]─────┤         |       |
                                   [R1]→GND   [BST]←[Cbst 100nF]→SW
                          [GND]→GND           [GND]→GND
```

**设计要点**：
- 反馈分压：Vout = 0.8V × (1 + R1/R2)（以MP1584为例，Vref=0.8V）
- 输入电容紧靠VIN和GND引脚（最重要！寄生电感会引起电压尖峰击穿MOSFET）
- 电感按公式计算：L = (Vin-Vout)×D/(ΔIL×fsw)，ΔIL取30%×Iout
- SW节点铜皮面积足够但不宜过大（EMI控制）
- 反馈走线远离SW和电感（噪声敏感）

### 2b. DCDC Buck（以LM2596/XL1509为例，固定输出版本）

> 来源：RYDZ智能车

```
[VIN 12V] → [自恢复保险丝] → [开关] → [680μF电解 // 100nF陶瓷] → [LM2596 VIN]
                                                                    → [LM2596 GND] → GND平面
                                                                    → [LM2596 OUTPUT] → [肖特基二极管阴极]
                                                                                      → [一体成型电感 33μH/4.5A]
                                                                                      → [输出电容组：100μF电解 // 100nF陶瓷] → VCC
                                                                    [肖特基二极管阳极] → GND
                                                                    → [LM2596 FB] → VCC(短接，固定输出版本)
                                                                    → [LM2596 ON/OFF] → GND(使能)
```

**设计要点**：
- LM2596 vs LM2596HV：封装和引脚完全一致，HV版本仅输入电压范围更宽（60V vs 40V）。12V转5V选普通版即可
- 同PCB可兼容多档固定输出版本（3.3V/5V/12V）：仅换焊接芯片，输出网络用通用名VCC，背面丝印注明
- **电感选型铁律**：务必用一体成型电感（屏蔽式），不用开放式。开放式电感磁通量泄漏导致EMI，"莫名其妙的问题"
- 电感额定电流 > 芯片输出电流×1.5（3A输出 → 选4.5A额定电感）
- **续流二极管**：必须用肖特基（响应速度快），额定电流留50%余量（3A输出 → 选5A二极管，避免"跑不满"）
- 输入输出均用"大电解+小陶瓷"并联实现宽频滤波
- **功率回路走线**：输入电容→芯片VIN→续流二极管→电感→输出电容→GND，铺铜代替走线（200~375mil宽）
- FB反馈引脚走线远离电感，避免电磁干扰
- 芯片散热焊盘（EP/GND）下方多打过孔到地平面

### 3. 锂电池充电电路（TP4056）

```
[USB 5V] → [TP4056 VCC]
            [TP4056 PROG] ← [Rprog] → GND  (设定充电电流: I=1200/Rprog)
            [TP4056 BAT] → [电池+]
            [TP4056 CHRG] → [LED红] → VCC  (充电中亮)
            [TP4056 STDBY] → [LED绿] → VCC (充满亮)
            [TP4056 TEMP] → GND (不用NTC时)
            [GND] → [电池-]
```

**设计要点**：
- 裸TP4056只负责单节锂离子电池CC/CV充电，不提供过放保护，也不能替代完整电池保护；只有额外含保护IC与背靠背MOSFET等器件的模块才可能具备过充/过放/过流保护，须核对模块原理图和准确料号
- 充电电流由PROG引脚电阻设定；典型关系为 `Icharge(mA) ≈ 1200 / Rprog(kΩ)`，以准确料号数据手册和热降额为准
- 典型Rprog=1.2KΩ → 1A充电电流
- 1S锂电池经LDO产生3.3V时须核对最低电池电压与dropout；若要求整个放电区间维持3.3V，应比较Buck-Boost等拓扑

### 4. 电池电量ADC分压采样

```
[VBAT] → [R1 10K] → [ADC_IN] → [R2 10K] → GND
                |
              100nF（可选滤波）
                |
               GND
```

**设计要点**：
- 分压比计算：Vadc = Vbat × R2/(R1+R2)
- 2S锂电池满电8.4V → 分压比至少 3.3/8.4 ≈ 0.39，例如R1=20K,R2=10K → 分压比0.33
- 分压电阻推荐0.1%精度，确保分压值与理论值一致
- BOM优化：用两个10K串联代替一个20K（减少物料种类）
- ADC采样后软件做均值滤波，去除最大值最小值后取平均

## MCU系统电路

### 5. MCU最小系统（结构示意，非跨型号定版）

以下只展示常见功能块，不代表所有MCU都具有相同复位极性、内部上拉、BOOT脚、模拟电源或去耦值；先按准确料号的数据手册、硬件设计指南和当前勘误逐引脚建立检查表。

```
[VCC_3V3] → [MCU 各VDD引脚]
             [MCU VDDA] → [10Ω磁珠/0Ω] → [VCC_3V3] + [1μF+100nF]→GND（模拟电源，可选）
             [MCU VREF+] → [VCC_3V3] + [100nF]→GND（ADC参考，可选）
             [MCU NRST] → [100nF] → GND  （上电复位）
                       → [10KΩ] → VCC_3V3（可选，内部已有上拉）
             [MCU BOOT0] → [10KΩ] → GND  （从Flash启动）
             [MCU 各VDD] → [100nF] → GND（每对VDD/VSS放一个）
```

**设计要点**：
- 每个电源域的去耦数量、容量、ESR与摆放按准确数据手册实现，并形成电源脚到电容到地的短回路
- 复位极性、外部RC/上拉、阈值与上电时序强依赖器件及硅版本；当前勘误优先于教学案例
- 启动脚名称、默认上下拉和启动状态组合按准确器件核对，不假定所有MCU都有BOOT0/BOOT1
- VDDA、VREF、内部稳压电容脚等特殊电源/参考脚逐一核对，不能按普通VDD处理

### 6. 晶振电路

**无源晶振**：
```
[MCU OSC_IN] ←→ [无源晶振] ←→ [MCU OSC_OUT]
                      |
                    [CL1]→GND     [CL2]→GND
```
- CL1=CL2≈2×(CL_crystal - Cstray)，Cstray≈3~5pF
- 晶振标称12pF → CL1=CL2≈18~22pF（C0G/NP0材质）

**有源晶振（4脚）**：
```
[VCC] → Pin4(VDD)
[GND] → Pin2(GND)
[MCU OSC_IN] → [器件数据手册定义的OUT脚]
[其余脚] → 按准确振荡器的OE/ST/NC定义处理
```
- 四脚有源振荡器的Pin1/Pin2/Pin3/Pin4功能并非跨料号统一；OE/ST脚不得凭经验悬空，按器件手册设定确定电平
- 时钟输出接MCU规定的外部时钟输入脚；MCU另一振荡脚如何处理按MCU手册核对

**PCB布局铁律**：
- 晶振紧靠MCU
- 负载电容紧靠晶振
- 晶振下方不布任何走线
- 远离板边
- 周围加禁止铺铜区

### 5b. 51单片机核心板最小系统（STC89C52RC）

> 来源：Expert强化篇51核心板

**供电与去耦**（以下按选择5V供电示意）：
```
[Type-C 5V] → [开关] → [VCC_5V] → [MCU VCC]
                         └→ [数据手册要求的去耦] → GND
```
- 若选择5V供电就直接使用经保护/开关后的5V电源；若选择其他电压，先按准确后缀型号和负载验证工作范围，再设计相应稳压器，不能同时画3.3V稳压却声称MCU使用5V
- 芯片VCC引脚附近放0.1μF去耦电容

**晶振电路**：
```
[MCU XTAL1] ←→ [12MHz无源晶振] ←→ [MCU XTAL2]
                    |              |
                  [47pF]→GND    [47pF]→GND
```
- 谐振电容47pF来自数据手册推荐值
- 晶振紧贴单片机晶振引脚，保持轴对称布局

**复位电路**：
```
VCC → [电容] → [MCU RST]
                  ├→ [电阻] → GND
                  └→ [按键] → VCC
```
- 对典型高电平有效的8051复位，上电时由电容产生高脉冲、随后由下拉电阻释放；电容、电阻、按键接法和最小脉宽必须按准确STC型号手册验证

**P0口上拉（关键！）**：
```
[P0.0~P0.7 各引脚] → [10KΩ 排阻/独立电阻] → VCC_5V
```
- P0口上电复位后为开漏输出，必须外接上拉才能输出高电平
- P1/P2/P3上电后为准双向口，无需上拉

**LED驱动（灌电流模式）**：
```
[所选MCU VCC] → [限流电阻] → [LED阳极] → [LED阴极] → [MCU P1.0]
```
- 51单片机灌电流能力远大于拉电流，LED必须阴极接IO口
- IO口输出低电平时LED点亮

**Type-C供电（6pin仅供电）**：
```
[Type-C VBUS] → VCC5
[Type-C GND] → GND
[Type-C CC1] → [5.1KΩ] → GND
[Type-C CC2] → [5.1KΩ] → GND
```
- 作为Type-C受电端/UFP时，CC1/CC2各自的Rd用于方向与连接识别；5.1K是常见标称候选，准确值与可取电流按USB Type-C规范及接口控制方案核对，不能等同于完整USB-PD协商

### 5c. MSPM0核心板最小系统（TI MSPM0G3507）

> 来源：RYDZ MSPM0系列

**供电**（历史案例，必须按当前数据手册/勘误复核）：
- 工作电压1.62V~3.6V（典型3.3V）
- LDO方案：M16211C33（输入6V，输出3.3V，500mA），也可用AMS1117-3.3
- LDO或DC/DC均须按输入范围、效率、纹波、瞬态、噪声敏感电源域和布局要求选择；满足芯片指标的DC/DC并非天然不可用

**特殊引脚处理**：
```
[PA2] → [100KΩ ±0.1%] → GND     ← 精度必须0.1%，1%精度会导致芯片异常！
[VCORE] → [470nF] → GND          ← 仅接电容，不得接其他电路，紧靠芯片
[NRST] → [47KΩ] → VCC_3V3        ← 上拉
       → [100nF] → GND            ← 滤波
       → [按键] → GND             ← 手动复位
[PA18/BSL] → [47KΩ] → GND        ← 空闲保持低电平
           → [按键] → VCC_3V3     ← 按下触发BSL
```
- 上述NRST阻容是历史案例值，不得跨型号/硅版本照抄；先查当前器件勘误，若勘误给出特定RC或复位保持时间，以勘误为准
- PA0/PA1可耐受5.5V，通过10K上拉到3.3V或5V
- 每对VDD/VSS放10μF+100nF去耦电容并联

**晶振电路**：
```
[PA5 HFXIN] → [15pF]→GND → [40MHz无源晶振1脚]
[PA6 HFXOUT] → [15pF]→GND → [40MHz无源晶振3脚]
```
- 负载电容15pF为晶振数据手册标注值
- 晶振下方顶层+底层均禁止铺铜

**SWD调试接口（4pin）**：
```
1: SWDIO (PA19)
2: SWCLK (PA20)
3: VCC_3V3
4: GND
```

### 7. ESP32一键自动下载电路

```
[USB] → [CH340C] → [ESP32]
        [CH340C RTS#] → [三极管Q1基极] → 控制 [ESP32 EN]
        [CH340C DTR#] → [三极管Q2基极] → 控制 [ESP32 IO0]
```
- 两个NPN三极管（如S8050）+ 基极限流电阻
- RTS#/DTR#信号控制EN和IO0时序，实现自动进入下载模式

## 电机驱动电路

### 8. 直流电机H桥驱动（RZ7899）

```
[VBAT] → [RZ7899 VCC]
          [RZ7899 IN1] ← MCU_GPIO1
          [RZ7899 IN2] ← MCU_GPIO2
          [RZ7899 OUT1] → [电机A端] ←→ [104电容] → [电机B端]
          [RZ7899 OUT2] → [电机B端]
          [RZ7899 GND] → GND
```

**真值表**：
| IN1 | IN2 | 状态 |
|-----|-----|------|
| H | L | 正转 |
| L | H | 反转 |
| H | H | 刹车（短路制动） |
| L | L | 滑行（惯性停止） |

**设计要点**：
- 电机电源直接接电池（不经LDO），避免LDO过流
- 电机两端并联104(100nF)电容，**焊在电机端子上**而非PCB上（厂家建议）
- 电机驱动回路面积最小化，减少EMI
- 多路电机PWM时注意定时器通道分配（同一侧用同一定时器）

### 9. MOS管电机驱动（NMOS低端驱动）

```
[VBAT] → [电机+] 
[电机-] → [NMOS漏极(D)]
[NMOS源极(S)] → [GND] ←→ [电流检测电阻Rsense]→GND
[NMOS栅极(G)] ← [MCU PWM输出] → [Rg 10Ω~100Ω]
                 [Rgs 10KΩ] → GND（防悬空）
```

**设计要点**：
- NMOS低端驱动是最简单的电机开关方式
- Rg限制栅极充放电电流，减少EMI
- Rgs确保MCU未初始化时MOSFET可靠关断
- 电机并联续流二极管（肖特基），反向耐压 > VBAT × 2
- **绝对禁止上下桥同时导通**（H桥场景，瞬间短路烧管）

### 8b. TB6612双路电机驱动

> 来源：RYDZ智能车

```
[VM 12V] → [100μF电解 // 100nF陶瓷] → [TB6612 VM]  (电机电源，直连输入电压)
[VCC 3.3V] → [TB6612 VCC]                          (逻辑电源)
[TB6612 STBY] → [10KΩ上拉] → VCC_3V3               (使能，高电平正常工作)
[TB6612 GND] → GND

[MCU PWM] → [TB6612 PWMA]
[MCU GPIO] → [TB6612 AIN1]
[MCU GPIO] → [TB6612 AIN2]
[TB6612 AO1] → [电机A+]
[TB6612 AO2] → [电机A-]

[MCU PWM] → [TB6612 PWMB]
[MCU GPIO] → [TB6612 BIN1]
[MCU GPIO] → [TB6612 BIN2]
[TB6612 BO1] → [电机B+]
[TB6612 BO2] → [电机B-]
```

**线宽标准**（TB6612持续输出1.2A）：
| 信号类型 | 线宽 | 说明 |
|----------|------|------|
| 控制信号（PWMA/IN1/IN2/STBY） | 10mil | 普通信号线 |
| 电机驱动线（AO1/AO2/BO1/BO2） | 20mil | 承载1.2A电流 |
| VM电源输入 | 30mil | 供电干路 |
| 电流>2A | 铺铜代替走线 | 过流能力强 |

**布局要点**：
- 电机驱动信号线不要从大电流电机输出线中间穿过（电磁干扰）
- 信号线从芯片下方或板边绕行
- 多路TB6612可复制已有的布局布线区域，修改网络名后缀即可

**排针间距规范**：设计为2.54mm的整数倍（如15.24mm=6×2.54），使模块可直接插入面包板

### 10. 有刷电机H桥集成芯片（DRV8870）

```
[VBAT 6.5~45V] → [DRV8870 VM]
                  [DRV8870 IN1] ← MCU_GPIO1
                  [DRV8870 IN2] ← MCU_GPIO2
                  [DRV8870 OUT1] → [电机+]
                  [DRV8870 OUT2] → [电机-]
                  [DRV8870 ISEN] → [Rsense] → GND
```

- 最大3.6A峰值电流
- 内置过流/过热保护
- 外围极简

## 传感器接口电路

### 11. 红外循迹传感器（TCRT5000 + LM393比较器）

```
[VCC] → [R1 220Ω] → [红外发射管] → GND
[VCC] → [红外接收管] → [LM393 IN+]
[VCC] → [电位器/分压] → [LM393 IN-] （调节灵敏度）
[LM393 OUT] → [上拉电阻 10KΩ] → VCC
[LM393 OUT] → MCU_GPIO（数字高低电平）
```

**设计要点**：
- 比较器输出为开漏，必须外接上拉电阻
- 电位器调节比较阈值（灵敏度），建议用多圈精密电位器
- 多路循迹（5路），间距根据黑线宽度和赛道曲率设计
- 也可用ADC直接采集红外接收管电压（模拟型循迹，灰度级更丰富，但算法更复杂）

### 12. 超声波测距（HC-SR04类模块）

```
[模块规定电源] → [HC-SR04类模块 VCC]
[MCU GPIO输出] → [HC-SR04 TRIG]
[MCU GPIO输入] ← [分压/电平转换（按需）] ← [模块 ECHO]
[GND] → [HC-SR04 GND]
```

**工作原理**：
1. MCU发10μs高电平到TRIG
2. 模块自动发8个40KHz脉冲
3. ECHO输出高电平，时长与距离成正比
4. 距离 = ECHO高电平时间(μs) × 340(m/s) ÷ 2 ÷ 1000

**设计要点**：
- 常见HC-SR04版本按5V供电且ECHO可能输出5V逻辑；3.3V MCU必须先核对实际模块版本和输入耐压，必要时使用分压或电平转换
- TRIG电平门限、ECHO极性/脉宽、量程、盲区和精度均按实际模块规格书核对，不把教学参数当成系列通用值

### 13. 按键检测电路

**上拉式（推荐）**：
```
[MCU GPIO] ← [按键] → GND
[MCU GPIO] → [上拉电阻 10KΩ] → VCC（可用MCU内部上拉替代）
```
- 按下时GPIO读低电平，松开时读高电平
- 软件防抖：检测到低电平后延时20ms再读取确认

**下拉式**：
```
[MCU GPIO] → [按键] → VCC
[MCU GPIO] → [下拉电阻 10KΩ] → GND
```
- 按下读高电平，松开读低电平

**ADC按键（多按键复用一个ADC引脚）**：
```
[ADC_IN] → [R1 1K] → [K1] → GND
          → [R2 2K] → [K2] → GND
          → [R3 3K] → [K3] → GND
```
- 不同按键按下时ADC读取不同电压，识别按键号
- 原理：不同下拉电阻产生不同分压值

## 通信接口电路

### 14. USB转串口（CH340C）

```
[USB_D+] → [CH340C UD+]
[USB_D-] → [CH340C UD-]
[CH340C TXD] → [MCU RX]
[CH340C RXD] → [MCU TX]
[CH340C VCC/V3] → [按准确CH340C数据手册所选3.3V或5V供电模式连接]
[USB_VBUS] → [CH340C VCC]（如需USB供电）
```

**设计要点**：
- TXD/RXD要交叉连接（CH340的TX接MCU的RX，RX接MCU的TX）
- CH340C在3.3V与5V供电模式下的VCC/V3接法、去耦和UART输出电平并不相同；按准确数据手册逐脚实现并核对MCU输入容限
- 使用Type-C接口时，CC1/CC2各接5.1K下拉电阻到GND（识别为UFP设备）

### 15. I2C总线设计

```
[MCU SDA] ←→ [上拉 4.7KΩ] → VCC
             ←→ [器件1 SDA]
             ←→ [器件2 SDA]
[MCU SCL] ←→ [上拉 4.7KΩ] → VCC
             ←→ [器件1 SCL]
             ←→ [器件2 SCL]
```

**设计要点**：
- I2C为开漏输出，**必须**外接上拉电阻
- 典型值4.7KΩ，可放宽到2.2KΩ（高速）~10KΩ（低速）
- 阻值越小 → 上拉越强 → 速度越快，但功耗越大
- 若传感器模块内部已集成上拉，外部可省略（查看模块规格书确认）
- 多器件共享同一总线，通过不同7位地址区分

### 16. SPI总线设计

```
[MCU SCK] → [器件 SCK]
[MCU MOSI] → [器件 MOSI]（Master Out Slave In）
[MCU MISO] ← [器件 MISO]（Master In Slave Out）
[MCU CS/SS] → [器件 CS/SS]（片选，低有效）
```

**设计要点**：
- MOSI和MISO不交叉（与UART不同）
- 每个从器件独立CS线
- 高速SPI（>10MHz）注意走线长度匹配
- MISO建议加10KΩ上拉（防止从器件未驱动时浮空）

### 17. UART/蓝牙模块（HC-05）

```
[MCU TX] → [HC-05 RXD]（交叉连接）
[MCU RX] ← [HC-05 TXD]（交叉连接）
[合规电源] → [HC-05裸模块或底板的VCC]
[HC-05 EN] ← [MCU GPIO]（可选，进入AT模式）
[HC-05 STATE] → [MCU GPIO]（可选，连接状态指示）
```

**设计要点**：
- TX/RX必须交叉（与I2C/SPI不同）
- 波特率默认9600或115200，需匹配
- 区分裸蓝牙核心模块与带稳压/分压底板：供电脚允许范围和UART IO电平不是同一概念，必须按实际板卡原理图与芯片规格核对
- 接收使用中断方式，接收完成后解析指令

### 18. RS-485通信

```
[MCU TX] → [MAX485 DI]
[MCU RX] ← [MAX485 RO]
[MCU GPIO] → [MAX485 DE + RE]（收发控制：高=发送，低=接收）
[MAX485 A] ←→ [BUS_A] ─────────────────→ [其他节点A]
[MAX485 B] ←→ [BUS_B] ─────────────────→ [其他节点B]
[BUS_A] ─── [RTERM，跨接A-B，仅物理端点] ─── [BUS_B]
[总线规定的偏置位置] → [失效保护偏置网络（按收发器/节点/线缆计算）]
```

- 可达速率与距离取决于线缆、拓扑、收发器和环境，不把“>1000米”作为无条件能力
- 终端只放在总线物理两端，阻值按线缆特性阻抗与收发器要求确定
- 若收发器未提供足够的内部失效保护，只在系统规定的位置设置一组偏置；不能让每个节点机械复制上下拉

## 模拟前端电路

### 19. 信号调理：电压衰减+直流偏置（y=Ax+B）

**场景**：将±15V外部信号转换为0~3.3V供ADC采集

```
[Vin ±15V] → [R1 900K] → [节点A] → [R2 100K] → GND（1/10分压）
[节点A] → [运放同相端+]
[1.65V偏置] → [R3 10K] → [运放反相端-]
[运放输出] → [R4 10K] ← [运放反相端-]（同相放大×2）
[运放输出] → [R5 100Ω] → [钳位二极管] → ADC_IN
```

**数学建模**：
- y = Ax + B，其中y∈[0,3.3V]，x∈[-15V,+15V]
- 解得 A=0.11（约1/9），B=1.65V
- 整体增益 = 1/10分压 × 2倍放大 × (1+1.65V偏置) ≈ 0.11×Vin + 1.65

**设计要点**：
- 输入电阻约1MΩ（标准示波器输入阻抗）
- 偏置电压1.65V可由3.3V分压 + 电压跟随器产生
- 输出串小电阻（100Ω）防止运放直接驱动电容导致自激振荡
- 输出可使用限流阻抗+双二极管钳位作为候选，但须核对ADC允许注入电流、VCC吸收回灌能力、掉电反向供电和故障功耗，不能仅凭二极管存在就声明安全
- 高频场景分压电阻并联补偿电容（几pF）

### 20. 迟滞比较器触发电路（AP331）

```
[信号输入] → [AP331 IN+]
[触发电平] → [AP331 IN-]（DAC输出 或 PWM+RC滤波）
[AP331 OUT] → [上拉电阻 10KΩ] → VCC
[AP331 OUT] → [R1 1MΩ] → [AP331 IN+]（正反馈，产生迟滞）
```

**设计要点**：
- **必须使用迟滞比较器**（加正反馈电阻），不能用普通比较器
- 原因：输入信号的小毛刺/抖动会导致误触发，迟滞消除此问题
- 迟滞窗口宽度由R1和上拉电阻比例决定
- AP331为开漏输出，必须加上拉电阻
- 上拉电阻不能太大（>100K），否则影响输出翻转速度
- 触发电平如无DAC可用PWM+两级RC低通滤波生成

### 21. 模拟输出通道（DAC→信号源）

**场景**：将MCU的DAC输出(0~3.3V)放大为±10V信号源

```
[MCU DAC] → [RC低通] → [运放反相端-]（反相放大器×6）
                         [运放输出] → [49.9Ω] → [继电器切换] → [BNC输出]
                                       [100nF旁路]→GND
```

**数学建模**：
- y = Ax + B，y∈[-10V,+10V]，x∈[0V,3.3V]
- A≈6.06（放大6倍），B=-10V（偏移）
- DAC输出先经小电容低通滤波（消除量化噪声）
- 输出经49.9Ω达到50Ω输出阻抗（匹配标准信号源）

## 保护与隔离电路

### 22. 输入保护：钳位电路

```
[输入] → [R限流 1K] → [节点] → [后级电路]
                      [节点] → [肖特基二极管1 阳极] → [阴极接VCC]
                      [节点] → [肖特基二极管2 阴极] → [阳极接GND]
```

- 当输入电压 > VCC + Vf时，二极管1导通，电流流向VCC
- 当输入电压 < GND - Vf时，二极管2导通，电流从GND流入
- 实际钳位电压随器件、电流和温度变化，不能无条件保证在 `GND-0.3V ~ VCC+0.3V`
- 限流阻抗不仅要保护二极管，还要满足后级允许注入电流；同时核对VCC吸收回灌能力、掉电反向供电和故障功耗，必要时使用TVS/专用保护或独立钳位电源

### 23. 电源防反接保护

**方案一：串联二极管**（简单但有压降）
```
[电源+] → [二极管] → [电路VCC]
```
- 肖特基二极管Vf≈0.3V，1A时损耗0.3W

**方案二：PMOS防反接**（推荐，无压降低损耗）
```
[电源+] → [PMOS漏极(D)] 
[PMOS源极(S)] → [电路VCC]
[PMOS栅极(G)] → [电阻 100K] → GND（或接电池-）
```
- 正接时PMOS导通（Vgs<0），压降=Id×Rds(on)极小
- 反接时PMOS关断，保护后级

### 24. 数字/模拟地与回流策略

```
[数字电路地] ─┐
              ├→ [连续、低阻抗的GND参考面；通过布局控制回流路径]
[模拟电路地] ─┘
```

**设计要点**：
- 默认采用连续GND参考面，通过功能分区、器件邻近放置和受控回流路径隔离敏感模拟电路与高 `di/dt` 数字/开关回路；不要让高速信号跨越平面缝隙
- 只有准确芯片数据手册、隔离架构或经过回流分析的系统要求明确需要分地时，才设置AGND/DGND分区，并定义唯一、可验证的连接位置及跨域信号路径
- 0Ω电阻或磁珠不是通用“消噪”器件；使用前需核对直流电流、阻抗频谱、压降、谐振与故障回流，不能机械套用单点连接
- 模拟信号、参考源和采样回路远离开关节点，并让信号去程和回程保持紧邻

### 25. 光耦隔离电路

```
[MCU侧 3.3V] → [R1 220Ω] → [光耦LED阳极]
[MCU GPIO] → [光耦LED阴极]（拉低=导通）
[被控侧 12V] → [R2 1K] → [光耦晶体管集电极]
[光耦晶体管发射极] → [被控侧负载] → GND
```

- 两侧独立供电，实现电气隔离
- 适用于高压/长距离/噪声敏感场景
- 低速光耦（如PC817）适用普通数字信号
- 高速光耦（如6N137）适用通信/USB隔离

## 系统级设计方法论

> 来源：Expert入门篇P8、RYDZ智能车

### 系统框图与电源树设计

**系统框图(System Diagram)**：用矩形框+箭头描述功能模块及模块间通信方式
```
例（智能车）：
[电池12V] → [DC005接口] → [自恢复保险丝] → [开关]
    → [DCDC 12V→5V] → [核心板MCU] ←→ [TB6612×4] ←→ [编码电机×4]
    → [LDO 5V→3.3V] → [OLED/蓝牙/MPU6050/灰度传感器]
```

**电源树(Power Diagram)**：描述各路电源如何产生和分配
```
12V输入 → DCDC(LM2596) → 5V → LDO(AMS1117) → 3.3V (MCU/传感器)
                             → TB6612 VM直供 (电机驱动)
                             → 舵机接口直供
```

**GPIO分配表**：多引脚主控必备，格式：
```
| 引脚 | 功能 | 方向 | 备注 |
| PA0  | LED1 | OUT  | 板载指示灯 |
| PA2  | PWMA | OUT  | TB6612-A路PWM |
| PA9  | TX   | OUT  | 蓝牙模块 |
| PA10 | RX   | IN   | 蓝牙模块 |
```

### 原理图分图页设计

复杂工程分图页原则（来源：Expert入门篇P8）：
- 一页一功能模块（电源、主控、驱动、传感器、通信各一页）
- **前面几页放架构总览**：系统框图 → 电源树 → GPIO分配表
- 例：正点原子开发板分23页，前3页为架构图

### 模块化设计哲学（来源：RYDZ智能车）

整车控制板 = 核心板 + 稳压模块 + 电机驱动模块 + 外设接口，全部采用**排针/排母直插**连接。
- 好处：模块可独立替换、焊接简单（只需电烙铁，不需热风枪）、调试方便
- 设计时先导入已有模块的PCB封装（.elibz格式），在原理图中用网络标签连接
- 全插件 vs 全贴片：全插件设计仅需一把电烙铁；混合设计需要热风枪+电烙铁两道工序

### 核心板设计模板

MCU核心板应逐项核对的四类功能（不是固定拓扑）：
1. **电源与参考**：按输入、各电源域、电流、纹波和时序选择LDO/DC-DC及去耦
2. **时钟**：先判断内部时钟是否满足精度/协议；需要外部时钟时按MCU与晶体/振荡器手册设计
3. **复位与监控**：按复位极性、阈值、RC限制、勘误和上电时序设计，按键并非必需
4. **启动/下载/调试**：按准确器件的strap/BOOT架构、默认上下拉和调试接口实现，不假定存在BOOT0/BOOT1

**单面贴片原则**：所有元件放同一面，避免双面贴片（吹一面另一面锡熔化元件掉落，加工厂双面贴片多收约500元）

### 丝印设计规范（来源：RYDZ MSPM0、RYDZ智能车）

**正面丝印**：
- 每个IO口旁标注引脚名（如"A14"、"PA25"），空间有限时可省略"P"
- 电源引脚标注：5V、3V3、GND
- 画框线分隔各组引脚：横杠分上下行，竖杠分左右列
- 板名标题高度：80~120mil
- 引脚标注高度：60mil（正面）、50mil（背面）
- 开关方向标识：用半径10mil的圆形标明拨杆方向

**背面丝印（"硬件注释"）**：
- 板子名称和引脚数（如"MSPM0G3519核心板(80pin)"）
- 引脚定义表：`LED1=PB0, LED2=PB1`
- VCC对应关系：`若焊接3.3V版本芯片则VCC=3.3V`
- 注意事项：`禁止焊接ADJ版本`、`reset=低电平有效`
- 店铺/学校/个人信息
- 丝印离焊盘>1mm，否则焊接后排针/排母会遮挡文字

**丝印操作技巧**：
- 布线时隐藏丝印层避免干扰
- 对齐：先定首尾→框选整列→右对齐+垂直等间距
- 正面丝印画好后复制到底层丝印层做背面
- 用3D预览反复检查丝印越界、重叠、字体不一致

### 工程命名规范（来源：RYDZ智能车）

小车控制板命名格式：`[主控类型]-[芯片型号]-[工艺类型]`
- 第一字母：K=开发板作主控，H=核心板作主控，NC=芯片直接贴片
- 末尾：X=全插件，T=集成贴片
- 例：`K-RCF103-X` = 以RCT6开发板为主控的全插件控制板
